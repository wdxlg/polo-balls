# 凋零角色：基岩版实时三维动画与验收边界

入口：`scenes/characters/我的世界/凋零.tscn`；信标是仅供召唤的 `scenes/creatures/我的世界/凋零信标.tscn`，不进入独立选角列表。纹理及烘焙精灵在 `Images/characters/我的世界/wither/`，音效在 `audio/characters/我的世界/wither/`，脚本在 `scripts/characters/我的世界/wither/`。

**当前纠正（基岩版原版实时动画）：** 之前 Java 纹理重排生成的 `wither_front.png`/`wither_assembling.png` 只能作静态图，不满足原版人物动画要求；战斗中不再显示它们。新 `bedrock_rig.gd` 从 Mojang 官方 `bedrock-samples` 的 `wither_boss.geo.json` 建立可旋转的六骨骼三维模型，把原版 `wither_boss.animation.json`/控制器中的头部寻敌及躯干余弦摆动公式实时施加到每根骨骼。角色的 `Image` 直接显示不断更新的透明 `SubViewport` 三维画面，召唤时使用原版无敌材质与旋转，半血时显示原版膨胀护甲模型/蓝色材质；这不是播放单张贴图，也不是烘焙的动画帧。固定使用 Mojang `bedrock-samples` 提交 `46ba6ea985fb5a92d79a9419198f10dda14c199d`，`bedrock/SOURCE_MANIFEST.json` 含原文件路径与 SHA-256。基岩版源文件只作为模型与动画资源，游戏数值仍按本项目的定制规则执行。头部视线输入由 2D 战场的目标方向映射，三维投影/渲染器是 Godot 而非直接运行 Minecraft 客户端；不声称像素级复刻客户端输出。选择界面尚未实例化角色时可回退为静态缩略图；进入战斗后必须使用动态三维视口。

**尺寸和爆炸反馈修订（2026-09-24）：** 骷髅头从 32×32 缩到 16×16，威胁半径同步从 15 调为 8；凋零玫瑰从 42×42 缩到 20×20，触碰和威胁半径同步从 23 调为 11，药水光晕由 46×46 缩到 26×26。四块魂沙统一为 30×30 正方形：下部中央一块、上方 T 字横排三块，各边严格贴合；三颗召唤头统一 26×26 并与上排方块等距对齐。骷髅命中与苏醒后不再绘制自制圆形/闪光爆炸，而是调用项目已有 `MC爆炸.tscn`/`mc_explosion.gd`，视觉半径对应现有 64/110；仅由凋零的原版音效入口播放一次爆炸声，复用场景设置 `play_audio=false`，避免双响。一次爆炸伤害仍只结算一次，联机端按事件播放同一共享视觉，效果挂在 `MCLocalEffects` 而非即将消失的骷髅头上。无头 smoke 的几何/效果检查通过；真实 World **27 项检查、0 失败**，额外覆盖真实骷髅头碰撞恰好生成一个共享爆炸和缩小后的玫瑰威胁半径。尚未在完整 GPU 游戏画面中确认这组新比例（训练地图视口截图缩放太远，不作验收依据）。上述 27/27 为此前一次验证。其后共享脚本并发编辑曾短暂导致 World 启动报 `Identifier not found: Game`；没有覆盖其他任务文件。本次重测完整真实 World 已可运行，最新结果见下方“朝向与发射点修订”。

**旧朝向方案（已由下方“身体倾斜、头部索敌”修订取代）：** 战斗中的实时 3D 模型现在按移动、玩家瞄准、开火预备及冲撞的实际方向平滑旋转身体；三头分别相对身体追踪目标，独立缓动、俯仰，并对开火的那一颗头施加短暂后坐。对照真实 GPU 四向画面修正了三维相机朝向造成的左右反向问题；基类的 2D 水平翻转不再二次镜像已转向的三维视口。骷髅头按中、左、右循环从**当前每颗三维头部的嘴部骨骼投影位置**发射，弹道也从该位置重新指向敌人/玩家瞄准点，不再使用角色中心固定偏移。联机外观同步含身体方向及注视目标，但仍需双端实测。独立 Godot 无头 9/9 脚本/场景及三头投影与实弹朝向断言通过；真实 World/Map50x50 **36 项检查、0 失败**，含真实右行转身、三个实际弹体各自的骨骼发射位置和弹道。非无头 OpenGL3.3 GPU 直接渲染四向 192×192 视口，各方向均有约 4,359–9,621 非透明像素；人工核对正面、向右、背面、向左转身及标注的三个嘴部随骨骼移动。此验证不等于完整关卡中的逐帧视觉、玩家手感或双端联机验收。

**飞行骷髅头、黑色药水粒子和百分比持续伤害修订（2026-09-24）：** 按用户选择，飞行骷髅头从此前的 16×16 缩为 **10×10**，其 AI 威胁半径同步从 8 改为 5；只调整飞行弹体，三维本体的三颗头、放置时的召唤头及既有 64 半径共享爆炸不缩放。命中敌人和凋零玫瑰触碰产生的 `WitherStatus` 均复用女巫的 8 帧药水粒子 Sprite：黑色调、独立在战场空间向上飘，施加时立即生成并在状态期间持续生成，不再在角色子节点内绘制旧的紫色贴图。3 秒凋零期间每满 1 秒按**目标最大生命值的 2%**结算一次，正常完整持续时间共 3 次（基础总计 6%）；仍走正常的伤害归属和目标抗性流程，同一目标刷新持续时间而不叠层，长帧不会追加超过时长的伤害。独立 Godot 无头 smoke 9/9；真实 World/Map50x50 **41 项检查、0 失败**，包括即时/持续黑色女巫粒子、固定值改为最大生命百分比和三次伤害上限。本次尚未在完整游戏 GPU 画面和双端联机中人工验收新粒子。

**前后朝向历史方案（本体翻转已被下方新方案取代；骷髅头正立与玫瑰转化仍有效）：** 按实际四向 GPU 画面修正三维本体及三个骨骼头部的前后映射：向上显示白眼正面，向下显示背面，同时保留正确的左右转向及三头骨骼发射位置。飞行的骷髅头是正面图标，其眼睛和嘴始终正立；物理速度和撞击方向仍由 `heading` 决定，不再对整张正脸图片按弹道旋转导致朝左时上下倒置。新生玫瑰使用 Minecraft Java 1.21.11 官方 `block/poppy.png` 红花（源自 SHA-1 `ba2df812c2d12e0219c489c4cd9a5e1f0760f5bd` 的客户端 jar；单图 SHA-1 `cb489e07f65c94878d6bb757924326e8710ecf92`，见素材来源清单）；普通花踩中一次造成原有威胁标注值 **4 伤**并消失，不施加凋零。**只有骷髅头的爆炸**能将爆炸范围内且视线无遮挡的普通花转为凋零玫瑰，苏醒爆炸不会转化；转化后贴图变黑并显示药水光晕，踩中一次同样造成 4 伤、刷新 3 秒凋零状态，随后消失。两种花共用原有 20 像素视觉和 11 半径威胁，最多同时保留三朵。Godot 无头 smoke 9/9、真实 World/Map50x50 **49 项检查、0 失败**；非无头 GPU 复核四向模型：上方为带白眼的正面，下方为无白眼的背面。联机双方的花与转化事件、完整游戏镜头及实际手感仍待验证。

**最新朝向修订——身体倾斜、三头独立索敌（2026-09-24）：** 用户明确要求身体**不**因向上/向下移动而翻出正面或背面、也不因瞄准敌人而旋转。苏醒后六骨骼模型的本体保持正面朝向镜头（yaw=0），实际移动速度方向只控制平滑倾斜：上下移动调整前后俯仰（最大约 0.20 弧度），左右移动调整横向侧倾（最大约 0.26 弧度），停止移动后归正；召唤阶段的原版旋转保持不变。三颗头各自依照其当前三维嘴部投影到敌人位置的二维差值，独立平滑调整水平转头（最大约 1.1 弧度）与垂直俯仰（最大约 0.38 弧度）；敌人在角色下方时头向下看，而不是跟着身体转到背面，玩家主动瞄准时以瞄准点为准。发射点仍取每颗骨骼**实时**投影嘴部位置，三头后坐及右移/左移时跨方向索敌不变。旧文档中“身体按瞄准方向转身”“向下显示背面”的描述仅属历史方案，不再作为当前行为。离线 Godot smoke **9/9**；真实 World/Map50x50 **53 项检查、0 失败**，新增移动向右而目标转到左边、站立目标在下方、身体停下而头继续跟踪等断言。非无头 OpenGL GPU 复核五组倾斜/头部目标画面：正面始终可见，头部独立转向；完整游戏 GPU 镜头手感与双端联机仍待验收。

**资源与移动修订（2026-09-24）：** 之前的 `wither.svg`、`beacon.svg` 是非原版手绘占位，已从运行时全部替换；源码已删除占位文件。`fetch_vanilla_assets.py` 从 Mojang Java 1.21.11 官方 client.jar（SHA-1 `ba2df812c2d12e0219c489c4cd9a5e1f0760f5bd`）和资产索引（SHA-1 `adb0a43fae291fd88ee27d85a372ba6f2072b0a3`）提取 10 张游戏纹理、15 个原版声音，并逐一核验哈希。`SOURCE_MANIFEST.json` 列出精确 jar 路径和每个源素材 SHA-1。仅以原版 UV/方块纹理为像素来源，通过最近邻重排生成 2D 凋零、无敌凋零、骷髅头、信标精灵；药水/爆炸/魂沙/玫瑰/激光也改用原版纹理，凋零出生、开火、受伤、死亡、闲置、爆炸及信标声改用原版事件。伤害反馈继续复用项目已核实为 MC 原版的暴击/受伤音效。资源的使用和再分发须遵守 Mojang EULA / usage guidelines，不把衍生精灵描述成 Minecraft 官方提供的 2D 成品。常态 `wither.move()` 改为 `super.move()`，遵守统一 0.6 倍基础移速、操控/AI 方向、击退、碰撞及其他角色通用移动行为，不再按距离悬浮/停滞或直接改 `global_position`；冲撞单独用 `CharacterBody2D.move_and_slide()` 做真实碰撞。信标落地后的水平巡航仍按指定机制独立处理。

本轮按用户新版取代旧的三连中信标方案：500 血、放置点原地搭魂沙/三头、约 3 秒苏醒免伤，标准 `ball` 弹体击中时反弹；苏醒末端 110 半径预警爆炸 45 伤。骷髅每 5 秒发一次，直击 75，撞人/墙时 64 半径溅射 45（同目标不重复）；凋零效果持续 3 秒、每秒扣目标最大生命值的 2%（基础共 6%），刷新不叠加，角色变暗并持续出现黑色女巫式药水粒子。玫瑰每约 10 秒以普通红花生成、最多 3 朵；踩中普通花仅有 4 伤且花消失，受骷髅头爆炸影响后才转为一次性凋零玫瑰（4 伤并刷新凋零状态）。约 12 秒一次 130 距离冲撞，32 伤及击退。

首次半血生成 180 血下界之心；落地后用重力和地面判定在下方水平移动。每约 10 秒预警并发 1.5 秒激光，每半秒 12 伤；释放结束随机给本体 6 秒的速度、急迫、力量、抗性、再生之一，效果不叠加。角色、玫瑰、骷髅与激光暴露真实威胁区域；信标本体不把纯支持范围标为伤害。实际有效伤害 >50 播 MC 暴击，其余播放普通反馈，额外基础增益为 0 dB 并依伤害增加。
