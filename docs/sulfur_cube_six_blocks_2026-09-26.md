# 硫方怪：六方块实装与验证（2026-09-26）

## 实装

- 生命上限 500，基础攻击 48；仅蓝冰、岩浆块、蜜脾块、铁块、TNT、紫水晶块六种。选取其余五种之一时使用战斗随机数，而非旧版固定顺序；不含木块和其他提议方块。
- 蓝冰：脚下沿真实地图方块格铺设约 24px 方形冰径，落在冰上的任意单位获得 **1.65 倍自身速度**，离开后 0.18 秒不续期即消退，不给站立单位凭空添加移动方向。2 秒后依次覆盖原版裂纹贴图，4 秒后调用已有 `block_fragments.gd` 碎裂。蓝冰本体伤害按自身实际移动速度增大。
- 岩浆：使用公共火焰免疫查询、正面碰撞加燃烧；敌人碰真实顶部矩形时每 0.16 秒结算一次较轻伤害。与烈焰弹、烈焰火场共用 `mc_shared_burn.gd` 的施加/刷新入口和 `mc_shared_burn_status.gd` 的状态逻辑（继承原燃烧状态，不拷贝视觉或持续结算代码）。持续伤害按**实际扣血**通过 `hit_audio_gain.gd` 分级，超过 50 的伤害播放原版暴击音，并通过硫方怪 RPC 同步给另一端。火免仅在岩浆形态生效。
- 蜜脾：接触敌人时对其向外速度施加有限拉力，不锁死速度；自身能量足够高的外移可以脱离。
- 铁块：伤害减免 50%、走得慢；只做一次跳砸，跳跃时忽略角色碰撞但保留地图碰撞，仅下落的下表面能伤敌；砸完恢复碰撞，不连击。下落时间也同步给客户端用于实际威胁提示。
- TNT：切入即点燃；倒数后使用原有可复用爆炸特效，敌人受伤且击退、自身受伤；若仍存活便立即随机换为其他方块，沿爆炸前真实移动方向获得衰减冲量；从未移动过则不虚构方向。
- 紫水晶：使用 Java 26.2 官方贴图构成独立的四个实时立体晶体；只在四个晶体的实际区域发生高接触伤害；每块晶体以各自当时方向射出可撞墙的投射体，之后再生；切换时未射出的晶体碎裂。壳体与内部方块在当前 2D 场景中由实时 3D 渲染并投影，不是静态平面贴图。按反馈修正：四根晶体的根部**埋在内部方块里**，以不同斜角穿出半透明外壳；每根为四面锥形实体配原版晶簇交叉纹理，不再把四张竖立卡片放在外壳表面。接触区、威胁提示、碎裂点和发射点根据当帧 3D 晶尖投影实时计算；晶体尚未从内部生长出来的短暂插入动画期间不会凭空伤人。
- 音效沿用官方 Java 26.2 `entity.sulfur_cube.jump/squish/hurt/death` 样本；官方音效表不存在此生物专属 ambient/step 事件，不伪造该来源。接触与爆炸音量按实际扣血、网络由权威端发出。新增紫水晶贴图的精确 JAR 条目和 SHA-1 在 `Images/characters/我的世界/sulfur_cube/source/REDESIGN_SOURCE.json`。这些是游戏资源，不代表自由再分发许可。
