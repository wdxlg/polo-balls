# Minecraft 伤害音效统一修复（2026-09-28）

## 用户要求与范围

用户要求：修复全分区审计发现的问题，但保留有明确音效替换要求的例外，例如石矛。

44 个可选角色中，本轮修复审计指出的 **29 个问题角色**：26 个迁入实际受击结算反馈，另外为凋灵、凋灵骷髅、雪傀儡补全固有持续伤害反馈。其余 14 个已正确角色保留原有实现；石矛保留明确例外。

- 有效生命伤害 **>50**：MC 暴击；**≤50**：MC 普通受击。恰好 50 不暴击。
- 使用结算后的生命差，封顶到受击前剩余生命；不使用面板攻击量、技能种类、过量伤害或范围内最大伤害代替。
- 通用伤害音额外增益以 **0 dB / 1x** 为基线，复用现有 `hit_audio_gain.damage_gain`，随实际伤害增长，上限 +6 dB。
- 未修改伤害、攻击属性、冷却、AI/手控、命中几何、位移、阵营、召唤数量或素材。没有新增/重编码原音文件。
- 武器挥舞/发射/爆炸/专属材质命中、角色受伤叫声属于独立层，不批量重置音量或替换声音。

## 保留的明确例外

石矛代码、场景和素材未修改：

| 实际伤害 | 音效 |
|---|---|
| 0 < damage < 50 | 原版 `minecraft:item.spear.hit` |
| damage == 50 | MC 普通受击 |
| damage > 50 | MC 暴击 |

换阵/出刺事件也保持。原有石矛原音专项 128 项全部通过。

## 实现

新增 `scripts/effects/我的世界/mc_hit_feedback.gd`，只处理反馈政策与复用音频，不复制伤害算法。

### 1. 公共结算入口

`classes/ball.gd` 的位置伤害反馈与 hitbox 接触结算，在知道真实受击者和最终生命损失后调用 `settled(source,target,before,point)`。

- 位置/空间/分类伤害沿用原公开入口，纯生命伤害也沿用原通路。
- 船分摊等重定向先完成，反馈属于实际掉血的承伤实体，不凭原目标被命中就制造声音。
- 纯护盾吸收、无效/零伤害、不合法数值不产生生命伤害音。
- 旧公共非 MC 接触声仅对已迁移来源停用。非 MC 来源和已正确手动反馈的角色不被全局强制改变。

### 2. 一次结算一个通用反馈来源

`POLICIES` 明确列出当前 44 个角色的迁移策略。最派生脚本优先，避免鞘翅重锤长矛因继承旧重锤而被二次补音。弹体/击退派生节点通过现有 `projectile_interactions.source_of` 查来源；自有且已经正确的手动实现优先于主人的迁移策略。

删除或停止执行迁移角色的旧固定普通受击、名义伤害选音和聚合最大伤害反馈：

- 史莱姆、活塞、钓鱼竿、仙人掌、羊、雾中人不再固定普通受击。
- 守卫者的 `critical` 技能标记不再决定最终命中声音。
- 弓命中不再“旧普通受击 + 按名义伤害追加暴击”；满蓄力发射也不提前冒充实际暴击命中。蓄力粒子/正常发射声音保持。
- 天堂陨落长弓、木船的新旧 FX 调用不再按结算前伤害加播。
- 重锤、钻石剑、铁匠村民统一取公共受击结算结果。铁匠命中判定改为 >50；挥舞的 >100 选声规则不变。
- 末影人/蠹虫身体碰撞、恶魂/苦力怕爆炸、潜影弹、烈焰棒、悦灵召回旋转接触等缺口通过实际结算入口覆盖。
- 专属矛命中/进食/爆炸声保留为独立层，不把已有专属声音错误当成通用 MC 阈值实现。

### 3. 持续伤害适配

`finish(source,target,before,point)` 用于原本直接攻击已经正确、但状态脚本没有通用反馈的路径：

- 凋灵与凋灵骷髅共用凋零跳伤；来源释放后仍可按存续状态的实际掉血反馈。
- 雪傀儡冻结体内跳伤。
- 药水持续伤害与隐身接触伤害；来源若已被自动结算入口报告，适配器不再重复播放。
- 共享灼烧对自动迁移来源停止第二次补音，硫方怪原有正确链路保留。

### 4. 音量修复

羊旧命中使用 MC 普通受击素材，但挂在 `entity.sheep.hit` 别名下，原本绕过 0 dB 下限。本轮实际攻击迁入统一反馈，并给旧别名补上 0 dB 保底，防止旧调用再以 -2 dB 起播。

已有公共事件的负参数不再作为迁移角色的命中入口；非命中事件不扩大保底范围，避免改变脚步、呼吸和材质混音。

### 5. 网络与生命周期

新增 ball 上的 `request_mc_damage_audio` / `_receive_mc_damage_audio`：

- 真实承伤实体的权威端选择原音变体，使用可靠 RPC；接收端拒绝重复序号与无效变体。
- 不依赖一次性弹体存活，不用易在同帧吞掉多个命中的事件冷却去重。
- 实际播放复用 `mc_native_audio.queue_stream`，保留延后挂载、原场景弱引用、伤害优先、24 声部预算、录制总线与 World2D 隔离。
- 已结算伤害尾音可存续，正常暂停不发起新伤害声。声部预算仍可能替换旧声音，不承诺无限重叠声部。

### 验证边界与过程记录

- 这是专项与相关回归，不是所有角色、所有状态、所有对手组合的穷举对局。
- 首轮夹具的护盾上限未设置导致护盾用例失败，修正夹具后全部通过；没有修改游戏护盾算法。
- 网络首轮在 RPC 接收后立即比较播放器，未等待延后队列追上同一序号；补齐等待后实测双端一致。
- Steam 无头模式在该环境不提供 PCM，最终改用真实 OpenGL/音频后端完成同一专项，不将无头零帧说成音频通过。
- 爆炸后真实派生撞击可能是另一次结算；播放器断言按实际结算次数核对，而非错误地把每次范围攻击强行限制为一个声音。
- 仍有现有资源 UID/大小写警告，以及部分 World 夹具退出时 ObjectDB 告警。本轮不宣称已修复这些问题。
- 新旧声音均复用项目现有原版素材，没有引入生成仿制素材或改变许可声明。
