# 训练设置：事件骨架、雪环境与寒冷伤害

## 用户约定

- **设置 → 训练 → 事件**：默认关闭。打开才显示事件勾选区；只有已勾选且已注册的 ID 可参与抽取。当前注册表为空，明确显示“暂无可选事件”，没有伪造陨石、地震等事件，也没有为未来事件擅定触发周期。
- **环境**：默认“无”，目前支持“雪”。**初始没有积雪**。开始战斗后先有原版 Minecraft 飘雪，再逐步生成原雪傀儡地面雪；天气表现与地面玩法并存，不能互相替代。
- 环境地面雪不随时间融化；墙雪只有装饰，没有伤害、积寒、冻结或物理阻挡。关掉环境只删除环境层，不删雪傀儡的普通雪径。
- **雪球直击不是寒冷伤害**，仍走原普通命中和轻微击退；只有附加的寒冷状态受到寒冷免疫阻止。
- 雪地和冻结跳伤使用公共寒冷入口。雪傀儡与小雪人默认免疫寒冷伤害，也免疫寒冷值、减速、攻速降低和冻结。

## 唯一实现与公共入口

| 对象 / 入口 | 身份与载体 | 行为约束 |
| --- | --- | --- |
| `scripts/training/battle_conditions_catalog.gd` | 系统数据；无伤害 | `EVENTS` 是显式事件目录；`eligible_events` / `pick_event` 只取已勾选且仍存在的 ID。旧/未知 ID 可留在存档，但不会进入当前抽取池。环境、布尔值、去重有界 ID 列表统一规范化。 |
| `ui/battle_conditions_settings.gd` | 设置 UI；无伤害 | 复用现有设置行和标题，使用 `Game.set_runtime_game_setting`，不另开权限旁路。中英文来自 `translations.csv` 及编译镜像。 |
| `scripts/training/battle_conditions.gd` | 战场系统 / 环境中立伤害来源 | 每个 World 一个。权威端生成地面玩法；使用独立、可重演的 RNG，不消费其他系统的随机计数器。事件仅预留受权限/暂停约束的抽取函数及 `event_selected` 信号，尚无事件实例或自动调度。 |
| `snow_golem/snow_field.gd` | 稀疏地形危险区；环境接触 / 寒冷 | 沿用同一真实位移采样、可达性查询、逐目标冷却、伤害入口、冷值和命中音效。`environment_patches` 与普通 `patches` 独立归属/寿命，不为每格创建 Area2D、计时器或隐形角色。 |
| `scripts/training/snow_wall_view.gd` | 纯表现；无攻击/载体/伤害/状态 | **真实 3D 墙顶雪层 + 原版飘雪**。墙雪是 `snow_height2` 的 2/16 厚六面体、原版纹理及侧面 UV；方块主题直接挂入现有墙的 World3D/相机/灯光，蓝色仅增加雪的独立 3D 通道，不把原平面边框变成立体墙。天气用原版 64×256 降雪贴图三层移动，不画白点、不新造一套技能粒子模拟器。 |
| `snow_golem/cold.gd` | 共享状态；状态跳伤 / 寒冷 | 每名受害者仅一个寒冷条；沿用原缓速、冻结、易伤、冰壳、雪花与声音。所有本地添加、持续控制和复制状态都检查寒冷免疫。 |
| `snow_golem/snowball.gd` | 远程 / 弹体 / **普通直击**，另附寒冷 | 不因受害者寒冷免疫而抹掉普通伤害或击退。原敌我、主人/家族、拒绝命中与寿命规则不变。 |

公共角色入口：

```gdscript
victim.receive_cold_positional_damage(caster.attack_damage(multiplier), hit_point, false, caster)
victim.receive_cold_spatial_damage(amount, damage_space, ignore_block, raw_health)
if victim.can_receive_cold_status():
    COLD.ensure(victim).add_cold(cold_gain, freeze_duration, caster)
```

- `ball.DAMAGE_ELEMENT_COLD`、`cold_effect_ratio`、`get_cold_effect_ratio()`、`is_cold_immune()` 与 `can_receive_cold_status()` 是公共协议，不在每名角色复制免疫特判。
- `cold_effect_ratio=0` 或 `is_element_immune(&"cold")` 表示寒冷伤害与寒冷值/控制免疫。普通负面效果免疫也继续阻止积寒，但不擅自免除本可承受的伤害。
- 正的寒冷倍率只在公共结算入口缩放一次；**不把部分伤害抗性擅自等同于同倍率积寒抗性**。已有通用负面效果比例仍负责状态倍率。
- 工作区并行接入的分类体系把 `receive_cold_*` 作为 `receive_classified_*` 的薄封装，不能再在角色/环境调用前重复乘倍率。不要因整名角色叫“雪傀儡”就把雪球普通直击改成寒冷。
- 获得免疫时移除本状态的减速、攻速和易伤 Buff，释放本状态持有的控制租约，不解除其他眩晕/击退的锁。

## 参数、归属与生命周期

- 地面沿用 CELL=24 的原雪片。环境读取原雪傀儡场景默认参数：攻击 9、地面系数 1/3（默认每次 3）、间隔 0.5 秒、接触积寒 8、冻结 1.4 秒；不是另复制一份近似攻击算法。
- 冻结跳伤每 0.35 秒一次，通过公共寒冷入口并保留原忽略格挡策略；按有效来源当前攻击的 2/9 计算，默认仍为原 2 点基础跳伤，再受原冻结易伤及受害者防御影响。来源消失后使用最后有效强度，环境源不用伪装成隐形雪傀儡。
- 原完整/小型雪径仍分别按 8/4 战斗秒融化。普通雪径保留主人、家族和敌我规则；环境地面雪是中立危险区，寒冷免疫者不受影响。重叠地面共用一个目标冷却，不能双倍跳伤。
- 环境雪不按时间融化，但真实地面雪仍可被原南瓜造雪人流程消耗。墙雪不可被当作地面伤害/寒冷。
- **取消旧的 8 地面 + 4 墙面预铺及延迟种雪回调**。新局、暂停布阵、换图、重置/重打及重新启用雪时，积雪与天气动画时钟均从零开始。天气在运行后 0.9 秒内渐入；累计满 2 战斗秒才开始落地积雪，此后每 0.45 秒尝试一片。累计永久格仍上限 1024；候选、循环及位置尝试有界，不为每片雪/雪花建节点。空的手动布阵场没有存活战斗角色时，不越过原 World 的运行条件。
- 地面必须落在真实地板区域，不把多岛地图的总包围盒当作地板。普通障碍/墙的物理查询继续复用原雪地；地图几何变化会重建候选并裁切/剔除不再属于地板或墙的环境记录。
- 游戏暂停、SceneTree 暂停及零时间倍率不推进生成、伤害或寒冷计时。关闭环境保留普通雪径。重置/重打沿用 `BattleTransient` 清理并按当前选择重建；旧 field 排队删除时不抢占新 field 的稳定名称。
- 发育地图合并沿用原雪地的分区位移协议，环境格随所在分区移动并在重合时合并，不生成第二份伤害。
- 环境格、完整快照和冷值由权威端可靠同步。冷值路径相对于各自 field 的战场根，不误用另一个网络子世界。晚加入的永久雪不携带绝对时钟或融化截止值。晚加入应显示房主已经积累的雪，不能把“新局空白”误用为清除房主快照。飘雪仅各端本地表现，房客也会播放，但不生成伤害格或额外结算。
- Events/Environment 不是本机视觉白名单设置，使用现有房主共享与房客权限；Map_Background 仍是本机外观，墙雪按本机实际墙体显示。

## 原版 3D 墙雪与天气表现

- 素材为 Minecraft Java 1.21.5 原文件；路径、下载地址、SHA-256 与版权说明在 `Images/effects/我的世界/雪环境/SOURCE.json`。不是自绘/生成替代图，也不声称原版素材可自由分发。
- 墙雪顶面/侧面来自同一个 `ArrayMesh`：原模型 `[0,0,0]→[16,2,16]`，侧 UV `[0,14,16,16]`。CELL=24 对应厚度 3 世界单位；底部高度恰为现有墙顶。按真实支撑墙裁切纹理和几何，不覆盖门洞、不把雪画在墙的竖直侧面上。
- 复用 `地图立体墙.gd::append_world_cuboid` 的六面体构造；普通墙 `_add_block` 只委托给相同参数的公共函数，原位置/格宽/高度/侧 UV 不变。雪材质不自发光；使用同一太阳/环境及真实深度，适配已有多通道地板影子，旧渲染器无地板专用通道时不要求该常量存在。
- 方块主题雪层留在墙的背景通道；不把整个墙抬到人物前面，不改云、地板或状态框排序。蓝色边框保持原样，只有装饰雪片具有厚度。
- 本机主题变化只把复制来的墙记录投影到本机支撑墙；共享地面格、RPC 数据和危险区不改变。发育地图仍使用原有格位移协议，墙层跟随该位移。
- 天气是固定三次贴图绘制的世界坐标降雪层，覆盖真实岛屿总体范围及近侧天空。不同速度/尺度使用独立本地随机相位；不消费战斗 RNG、不创建碰撞、状态或音效。世界坐标使共享 World2D 的竖屏/录制视口也能看到同一飘雪，菜单 CanvasLayer 不被覆盖。
- 不使用 shader 的墙钟 `TIME`；只推进战斗 delta。暂停/零速停止漂落和渐入；关闭环境立即隐藏天气、释放雪网格，普通雪径和共有墙渲染器保留。删除 field 会解绑帧回调并释放外挂网格，避免重打残影。
- 分类保持既有登记：`battle_conditions.gd` 为环境系统、`snow_field.gd` 为地形危险区、`snow_wall_view.gd` 为纯表现。没有新增未登记的运行脚本；原寒冷/雪球分类不变。

## 威胁显示与重演

- 雪地使用一个 `AI_Hazard` 声明 `shape="compound"` 的精确矩形列表，共用分析器，不制造每片雪的代理碰撞节点。装饰墙、小型无害雪、失效来源与免疫受害者不产生伤害威胁。
- 新 `get_debug_hazard_info()` 可提供与具体受害者无关的全部有效危险区；原单一区域协议不变。
- 修正了已有 `begin_battle_random` 对“已保存的合法 seed”再次归一化而加 1 的问题。合法已保存 seed 直接复用，异常/越界输入仍经原归一化；否则标称“完全重演”会改变包括雪在内的每条随机流。
