# 丁某人睡觉（默认）

2026-09-29。本次仅新增本角色，不改石矛或其他既有角色招式。

## 用户确认与当前参数

- 默认分类，中文名“丁某人睡觉”，1000 HP，普通 ball 移动/墙面反弹；不附带身体碰撞伤害。本轮体型缩为原来70%（根scale 0.20→0.14，身体/碰撞/血条/数字一起缩小），速度170→100（公共基础移动倍率0.60，实际移速102→60）。这是针对用户反馈选择的本轮默认值。
- 闭眼时，每4秒一轮4个Z，间隔0.2秒；每发基础1伤害、有效生命伤害后公共0.1秒眩晕，轻微追踪。
- Z继承主人**当前**攻击属性；速度属性110（本轮由220减半），实际110世界单位/秒（Z自定义移动不套用人物0.60倍率）；转向上限35度/秒、寿命3.5秒。后面三个参数是实现默认值，不是用户指定值。
- 头部右上小数字60→0。到0隐藏数字，先0.28秒压扁并保持颤抖0.45秒，再睁眼、发出一次扩圈像素波；实际发波后睁眼2秒，再闭眼并显示60。参数为实现默认。
- 波半径320世界单位、扩圈0.8秒、半宽3.5；参数由本次实现选定。中心固定在苏醒位置，本体继续正常移动。
- 波接触每个敌人时读取**该敌人此刻的HP**，通过 `receive_classified_spatial_damage(..., ordinary, true, true)` 真伤入口结算，每波每目标一次。不读取丁某人的HP、不裸写目标health、不把无视格挡当成普通伤害。
- 这是公共raw-health路径：绕普通减伤与格挡，但保留金心吸收、特殊免疫/复活、载具路由与友方复制保护；不是抹掉特殊规则的强制删除。
- 暂停冻结计时与当前角色音频。眩晕打断剩余Z；60秒到点但不能行动时保留0，恢复后再苏醒。伤害禁用也抑制波伤害与威胁。
- C手控只有左键 `controlled_burst`；停掉AI主动连发，苏醒保持被动，未增加虚构按键技能。

## 公共机制与分类

- 角色、Z、波、音频适配器分别登记；角色 `awake` 区分 projectile / area 阶段。实际伤害分量均为ordinary，raw-health是结算策略，不新增伪造的damage_kind。
- Z复用 `weapon_tip_sweep.contacts` 的真实hurt形状扫掠，再走公共hitbox防御/扣血和 `apply_stun`。沿行程排序，友方不挡后方敌人，墙阻挡使用公共trace。
- Z接入 `projectile_interactions`：归属、反射、捕获、格挡、预测、羊毛；只补实际速度协议及网络本地Master解析，不建立角色私有黑白名单。
- 波复用公共精确形状候选、墙遮挡及 `pixel_arc.draw_ring`；48段胶囊组成上一/当前半径之间的扫掠环，避免低帧率漏过目标与终帧漏扫。AI/调试使用同一分段几何，目标已命中/友方/被墙挡住时不再声明该目标威胁。
- MC有效伤害音统一登记到 `mc_hit_feedback.POLICIES`：实际生命损失≤50普通、>50暴击，0伤害不响；不另手播第二遍。角色受伤/死亡猫叫属于角色反馈，不代替攻击命中结算。
- 死亡复用 `mc_visual_effects.death_pose` 独立红染翻倒/烟雾，不另建死亡状态机，保留默认DeathBell及公共战斗存续结算；Z与波不能延长选手存续。
- 原“丁某人睡觉”翻译键已同时存在CSV和生成镜像，沿用既有键并将英文映射改为用户指定的me，不重复增加键，也不顺手重生成其他角色尚未同步的翻译。
