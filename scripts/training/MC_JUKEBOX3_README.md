# 唱片机：20次命中成长 / 左右声道攻击 / 单侧180度

已通过用户指定MCP部署。仙人掌本轮未修改，仍每层40%最多200%、每刺基础5点。

## 行为
- 20次有效攻击命中叠满（原15），进度streak/20；音乐-10到-2dB、伤害1到3倍、单侧覆盖15到180度同步线性增加。基础Damage6、原曲播放速度1不变。
- 每个事件从身体左右各自边缘向世界左/右发射，不索敌、不随本体翻转交换声道。
- 每个事件共享一次命中结算：任一侧命中即可成功，只加一次；两侧全空才重置；同一侧命中通知/完成通知不会重复叠加。旧的按音乐发射顺序结算规则保留。
- 角度按发射时快照，扩散只增加半径。单侧最大180度，左右合计可覆盖整圈（用户明确选择此项）。
- 每道波仍可独立对目标伤害一次，左右事件共享的是成长计数，不是强行合并两个投射物的伤害。

## 音源事实与分析
三首游戏内原版OGG均是单声道，已核SHA1：
- Pigstep：48000Hz / 1声道 / 520峰。
- Otherside：48000Hz / 1声道 / 784峰。
- Cat：44100Hz / 1声道 / 513峰。
详见source_channels.json。现有曲目左右同峰同强度，不编造左右偏向，也未替换原曲。

新增离线analyze_channels.py与预加载music_channel_peaks.gd；事件为[时间,左峰,右峰]，-1表示对应侧没有峰。立体声处理使用共享归一化保留左右能量差、合并60ms以内双侧峰；仅一侧有峰时仅该侧发波。当前真实曲目全部单声道，真正偏声道行为仅以测试夹具验证，不能称为当前曲目本身存在立体声效果。
