# 我的世界角色 · 第六轮修改

已通过指定 MCP 部署到 `E:\godot\polo-balls`。请停止旧运行实例，再重新运行项目。

## 行为与数值

- **粘性活塞**：黏附期间关闭并持续维持目标实体碰撞层与掩码为零，受击区域保留；在双方物理更新后将目标固定到活塞当前前端，任意转向都跟随，不再被墙阻挡。结束恢复原碰撞及移动锁状态；若释放位置埋墙，尝试邻近安全点。黏住播放随机粘液块放置声，被黏住后受到活塞攻击另加粘液块脚步声，保留持续攻击且不与推开效果争夺控制。
- **守卫者**：每轮蓄力 1.8 秒、命中伤害 90（原为 0.38 秒/15）。有效目标在蓄力期间不会被更近敌人抢走；出四轴各 ±15°范围、遮挡或失控仍会中断。光束前 88% 从宽 2.5 渐增到 14，最后 12% 快速收至 1，再命中。保留原版 guardian_beam 纹理，不添加自绘亮芯。穿过光束的其他敌人伤害仍为 4。
- **恶魂**：火球伤害倍率 ×2；当前场景基础 Damage 32，对应未计增益等修正时 64。
- **钓鱼竿**：剑击伤害倍率 ×2.5；当前场景基础 Damage 20，对应未计增益等修正时 50。钩伤不改。

## 音效范围

按确认，本轮只修改新生物音效，旧生物保持原状。

- 恶魂闲置采用原版哭泣事件；守卫者主要闲置为弹跳声，另有低频低鸣；史莱姆无闲置声。
- 主要闲置等待完整声音播完，再等随机 3–7 秒。守卫者低鸣使用独立计时器，播完后随机 12–22 秒，首次 8–14 秒，不占用主闲置冷却。
- 三个新生物实际掉血且仍存活时，按 45% 概率播放受伤声；死亡声在回合结束停止战斗时仍可播放。
- 新增四个守卫者 land_idle 音频；粘液块 place/step 复用已有原版音频。来源及 SHA1 见 `extra_sounds.json`，远端副本为 `scripts/training/mc_new5_assets/MC_ROUND6_EXTRA_SOUNDS.json`。
- 原版素材及声音属于 Mojang/Microsoft，非免版税或宽松开源素材。本项目使用原版资源进行离线二维适配，不称为完整原版三维运行时渲染。

## 死亡效果

- 新史莱姆、守卫者、恶魂补与既有 MC 生物相同的染红、倒下和白烟。尸体副本独立于角色节点，角色删除不会截断动画。史莱姆正常分裂保留。
- 恶魂在地图外死亡时，尸体和白烟位于地图外遮罩之上。
- 木矛、重锤、钻石剑、钓鱼竿、粘性活塞五类物品统一碎裂：从当前可见原纹理切出碎片，包含适用的活塞头、杆、剑等部件；不是绘制替代碎片。
- 碎片向上飞出并旋转，按重力走抛物线；完全落出地图后删除，不在地图中途淡出。无碰撞，20 秒安全清理上限。
- 新死亡姿势、白烟及碎片使用本地特效容器，不直接放在多人角色生成器根节点。
