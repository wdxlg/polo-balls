# 木剑第三次调整

覆盖前两版中“淡入期停靠”“剑刃挥舞”“单部件存活时工作台保留”的规则。

## 修改

- 工作台仍从 20% 不透明度用 3 秒逐渐显现。未完全显现时，部件经过不会被工作台自动停住；完全显现且实际接触后才停靠。原接触减伤/回血规则未额外改动；合成仍要求显现完成后，两个存活部件连续接触 2.4 秒。
- 完整木剑和剑柄继续挥舞。剑刃改为固定攻击朝向、向前伸出再收回的直刺动画，不再绕轴挥舞；命中改为更窄的正前方判定。三种形态身体的普通移动、不主动追敌规则保持不变。
- 剑柄或剑刃任一个死亡，工作台立即关闭服务并破碎。用工作台原纹理切出碎片，沿既有物品碎片抛物线飞出地图后清理；不是仅隐藏工作台。
- 存活部件立刻失去工作台减伤、回血和合成，恢复正常行动。记录该家族的工作台已销毁，防止存活部件下一帧重新生成工作台。
- 死亡钩子和后续死亡状态回调去重，只破碎一次；正常合成消耗部件和工作台不触发死亡破碎。移除部件时也有成对完整性检查。
- 增加可靠工作台丢失通知及视觉快照销毁标记；未进行双客户端实测。
- 耐久仍为 45，攻击扣 1，实际掉血每 5 点扣 1（向上取整，单次 1–5）。
