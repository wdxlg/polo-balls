# 唱片机五项音乐机制

生产通过用户指定MCP部署至 E:\godot\polo-balls；不修改仙人掌。

## 实现
1. 低频重拍：35–180Hz能量正向变化识别低频瞬态，唱片机短促垂直震动，附加细低音弧；命中轻击退（约4–10世界单位再乘拍点强度，速度90），0眩晕、无控制锁、无额外伤害。
2. 中高频打击：180–2500Hz与4500–11000Hz的能量瞬态分别产生交叉敲击纹理与切向细碎短线，不加粗原音波，不额外生成可伤害投射物。
3. 音高：混音自相关估计70–1200Hz主导周期；置信度>=0.45才用音高改变装饰密度、音符高低/茎长。未改变播放速度、主波方向或角度。
4. 延音/断奏/休止：包络持续长度+周期置信度近似延音；>=0.22秒长尾，<=0.14秒缩短尾；尾宽上限24，主线仍<=0.55。休止事件不生成波、不产生失败结算；原始峰值序列自然不在无峰空白处强塞攻击。
5. 强弱拍：低/中/高频瞬态及峰强组合形成拍点显著度，控制主波亮度、身体脉冲和击退强度。不是固定BPM强制攻击，也不假定每四拍是强拍。

核心保留：原曲/原速、左右攻击、单侧180度上限、音量/瞬时响度决定大小与伤害、20次成长/3倍上限、落空每秒5层衰减和命中立即止衰减、插盘换盘、细波主题。

## 分析真实性与局限
使用原版三首OGG，SHA1见analysis_report.json。原文件均单声道；本轮没有新增/替换录音或生成鼓声。
离线分析24kHz/2048点窗/20ms步进，保留既有真实峰值时间。结果预加载于music_features.gd，战斗中不做FFT或分轨。
鼓类标签是频段瞬态的近似，主导音高可能包含伴奏或倍频误差；延音是混音包络保持时间近似，并非精确乐谱音符时值；强弱是拍点显著度，不是已识别拍号和小节重音。
实际原曲保留峰事件：Pigstep520、Otherside784、Cat513；各曲均有低频/高频/有置信音高/延音特征。原曲检测出的既有峰中无rest标记，静音处本就不产生峰；休止分支另外用夹具验证。
