# 唱片机范围/伤害成长与仙人掌反伤调整

已部署到 E:\godot\polo-balls，使用用户指定MCP、fresh read/hash patch。

## 生产数值
- 仙人掌：每层40%反伤幅度，最高200%；每刺固定基础5点；总数量 floor(actual_HP_loss * min(levels*0.4,2) / 5)，两边合计。护盾/防御仍由目标正常结算；输出不随本体Damage变化。例：两层掉100HP，总16刺；五层掉100HP，总40刺。
- 保留先快速胀粗再爆刺/弹性回缩、反伤±45°、主动±10°。
- 唱片机：生产场景Damage从12降低至6；初始音波总角15°。
- 音量进度 clamp(streak/15,0,1)；实际音乐-10→-2dB；伤害倍率1→3；总覆盖角15→360度。音乐速度始终1。完全落空后按原有有序结算清空连击，后续波恢复初始值。
- 攻击距离半径仍由音乐峰值决定125→225，未另外削减距离；用户在选项中确认范围按角度解释。
- 单道波在发射时快照角度，经RPC显式传参，随后半径扩大/峰值/本体连击变化均不改其角度。不追踪。峰值继续改变伤害、传播速度/距离、细线与拖尾；不再改变角度。
- 360°形成完整圆环，按实际弧段扫描hurtbox；每目标仅一次伤害；绘制与碰撞段数随角度/半径调整（弧长约8px一段，12–192段），避免整圈仍只有24段。
- 插盘/弹盘/抛物线/下一首流程、三主题和原有音效保留。
