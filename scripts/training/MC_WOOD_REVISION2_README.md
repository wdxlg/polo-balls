# 木剑第二次调整

本说明覆盖上一版木剑 README 中的耐久、受伤消耗、追敌/突刺和工作台生效规则。已通过当前 MCP 修改生产脚本。

## 本次确认的行为

- 完整木剑、剑柄、剑刃全部使用普通角色移动：不因敌人改变移动方向，不主动追敌，不使用部件加速或刺击冲刺。攻击独立朝敌人瞄准、挥舞，不改变行进方向。剑刃也有与其他形态相同的挥舞动画及扇形命中区域。
- 取消完整木剑自动架招，避免普通移动中自动进入旧架招节奏；手动技能架招与反击保留，但不再附加移动减速。
- 初始和重组后的耐久均为 **45**；每次成功发动攻击扣 1，空挥也扣，多目标横扫不重复扣。
- 实际掉血每 **5 点**扣 1，向上取整，单次限制 **1–5**。例如 1–5 点扣 1，6–10 点扣 2，11–15 点扣 3，16–20 点扣 4，21 点及以上扣 5。
- 工作台出生时为 **20% 不透明度**，用 **3 秒战斗时间**线性恢复到完全不透明。暂停时显现进度停止。
- 完全显现后，才允许两部分同时接触并累计 **2.4 秒合成时间**。显现期不预存合成时间，跨越三秒阈值的一帧也只计阈值之后的时间；直接调用完成函数不能绕过显现条件。
- 接触时停留治疗、50% 减伤和每秒 5% 上限回血保持不变，显现期也可治疗。依旧要求同一把剑的两个存活部件同时接触，缺一不可；不自动返回工作台。重组生命仍为两部分当前生命之和。
- 视觉状态同步包含工作台显现进度，用于已有客户端/迟加入客户端恢复表现；未做双客户端实测。
