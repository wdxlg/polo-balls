# 仙人掌/音符盒第三轮音效与细音波

已部署至用户项目。

## 修改
- 仙人掌生长放置声由-5dB升至+3dB（增加8dB），距离1400、衰减0.65，原音高0.8保留。
- 开始收细播放entity.puffer_fish.blow_out；进入胀开阶段播放entity.puffer_fish.sting。每轮每种只触发一次，不在每帧/回弹中重复；客户端视觉插值不重复触发权威事件。
- 音乐音量根据伤害倍率直接映射：伤害1→1.9倍时音量-10→-2dB，每次伤害加成增加都同步增大音乐音量，不再在伤害封顶前提前封顶。音乐始终1倍速，落空同时重置两项。
- 音波主线由1–2.8缩到0.20–0.55世界像素，约原来1/5；拖尾带宽10–24缩到3–7。保留三首歌配色/特色图形；最后对火星、音符做了可读性微调，不加粗主波。
- 真实受击箱扫描提高到24个弧段，按新细线宽扫掠，碰撞不退化为必中。
- 每次成功命中按实际HP损失播一次声音；>50为entity.player.attack.crit，<=50为共享MC普通受击音。0伤害的成功格挡反馈也只用低音量普通声。
- 命中声增益：clamp(-7 + 12*log10(1+实际伤害/10), -7, 4)dB。10/50/51/90实际伤害对应-3.388/2.338/2.424/4dB。音量有上限，不无限增大。
- 新短音效最多32个声部，暂停冻结，不会挤掉音符盒音乐播放器。

## 来源
新增7个原版音频从用户指定MCSounds API对应事件获取，CDN下载逐个核对SHA1，详见sources.json。未使用不存在的entity.puffer_fish.deflate事件，也未把膨胀音blow_up误当作蜇刺音。原音频版权保留，不表示取得额外发行授权。
