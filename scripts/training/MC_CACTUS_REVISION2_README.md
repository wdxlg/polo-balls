# 仙人掌第二版：短刺、射刺弹性动作、音效

已部署，音符盒生产代码未改。

- 刺：从原版 cactus_side.png 的刺像素(0,2)-(2,3)裁取并最近邻扩展为6×1细条。颜色为(186,191,149)和(159,167,109)，无箭头/箭羽、无额外染绿或45°偏角。保留一次伤害、附着与3秒消失。
- 射刺：0.26秒横向收细到0.70倍；0.08秒胀到1.24倍，在最大胀开时唯一发射；随后0.32秒阻尼弹性回弹。高度少量反向变化，视觉底部固定，血条跟随上沿。发射点用胀开后的真实两侧位置计算。此短暂动作不改变实体碰撞；每节成长仍改变实际碰撞。
- 暂停冻结动作；不能行动时取消未完成的准备；客户端只插值动作，不重复发射。
- 每次真实长高播放一次仙人掌放置音。Java原版仙人掌使用 block.wool.place，音高0.8，非自行捏造 cactus.place 事件。[2](https://minecraft.fandom.com/wiki/Cactus)
- 4个放置音从用户指定MCSounds API获取，下载逐个SHA1核对；sounds.json保留来源。音频保留原版权，不代表获得商业再分发授权。
- 接触伤害成功时新增项目共享MC受击音；飞刺原有共享MC受击音保持并验证只响一次，不重复叠音。

验证：GPU专项236/236（含音符盒回归，断言数会随随机刺数量变化）；实战14/14，预置生长进度后由真实物理更新完成两次成长、三轮射刺、接触受击声及音乐连击/落空重置。新模块诊断0。仍有既有UI UID回退及ObjectDB退出警告；本轮未双客户端联机实测。

专项 scripts/training/test_mc_cactus_revision2.gd，实战 test_mc_cactus_revision2_live.gd；通用 test_mc_cactus_note.gd 已更新至第二版。mc_cactus2/ 保存当前源码、素材与日志。
