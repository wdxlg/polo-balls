# 木剑第五次调整：无眩晕击退与分形态朝向

已通过当前 MCP 修改生产 `scripts/characters/我的世界/frontier/wooden_sword.gd`。

## 本轮行为

- 木剑、剑柄的击退改为纯推开：传入 `stun_duration=0`、`lock_control=false`，不新增眩晕，也不锁定对方移动/攻击。不会主动清除其他来源已有的眩晕。
- 木剑和剑柄平时保持原图姿态，仅左右翻转；向上、向下移动时保持此前左右朝向，不再按移动向量旋转整张图。攻击保留左右对应的挥舞，攻击开始时锁定本次挥舞侧。
- 剑刃沿实际速度向量朝向；速度为零时回退到移动方向。直刺也沿该方向伸出/收回，不因旁边目标的位置改朝向。
- 左右翻转使用项目原有 Shader 镜像；物理碰撞箱选择对应的镜像凸多边形，不通过负缩放制造视觉/物理不一致。碰撞箱依旧随攻击动作移动，仍然可以挥空、刺偏。
- 补齐客户端攻击视觉倒计时，并同步左右朝向、挥舞侧、剑刃运动朝向。未做双客户端实测。

数值未改：默认满蓄力伤害仍为木剑 34、剑柄 7、剑刃 43；击退距离 12/55/0（木剑架招反击 18）。耐久 45、实际掉血每 5 点扣 1（单次 1–5）、剑刃 0.20 秒直刺与 0.28 秒回充、工作台规则均保留。
