# 木剑第六版：去字、苦力怕样式条、整剑蓄力

已部署至 E:\godot\polo-balls，使用用户指定 MCP 修改。

## 行为
- 删除角色附加的剑柄/剑刃/耐久/攻击状态描述及旧攻击条；保留游戏通用生命数字。
- 删除架招格挡、减伤和反击增益；场景及运行时 Can_Skill=false。
- 整剑脚下共享苦力怕样式耐久条（45）；柄/刃无攻击或蓄力条。
- 工作台修复期间使用同一绘制器显示2.4秒合成进度。
- 整剑2秒蓄满，旋转并抬起，满蓄力持续颤动；AI无敌也蓄力，有近敌即可释放，满蓄力无敌时等待。
- 手动按住攻击蓄力，松开攻击；清除控制取消蓄力。远端松开/取消为可选角色回调，非木剑角色保持原行为。
- 整剑实际单目标伤害：零/半/满蓄力12/26/68；推力参数4.2/20.1/36。柄7伤害/55推力，刃43伤害/无推力；部件普通攻击，无蓄力倍率。
- 保留真实武器碰撞、挥空、零眩晕/零控制锁、45耐久消耗与拆分、独立部件生命、3秒工作台显现、双接触修复及单件死亡碎台。
