# 唱片机：落空衰减与瞬时响度

## 已部署
- 左右事件全空：启动每秒5层的连续衰减，不瞬间清空。层数为float、上限20，满层持续衰减4秒归零；暂停冻结。
- 任一真实波命中立即停止衰减，即使命中事件还在等旧事件的有序结算；即使是之前已命中过的波再次命中另一个目标，也只停止衰减，不重复授予同一攻击的层数。
- 保留音乐事件顺序授予命中层数，左右合计最多1层；比最近成功事件更旧的延迟落空不会重新启动衰减。已命中过的波完成时不重复报告成功，避免无新命中却止衰减。
- 当时响度取既有官方OGG离线20ms RMS平滑包络、按曲目归一化后的峰幅。不是随机大小，也不是任意时间固定生成攻击。无需新增音源。
- 幅度a在0–1：伤害=Damage × lerp(0.10,1.7,a) × 连击倍率；半径上限=lerp(50,225,a)；拖尾=lerp(1.5,7,a)；发射角=叠层角度上限 × lerp(0.2,1,a)。速度与细线宽度继续随峰幅变化。
- 叠层角度上限仍15→180度；起始弱音波可以小于15度。发出后角度固定，半径正常扩散。满层响峰180度，满层a=0.1时50.4度。两侧独立幅度、共享成长结算。
- 音乐原速、音效、左右波、单声道事实、20次叠满、3倍增伤上限、唱片生命周期、仙人掌均保留。
