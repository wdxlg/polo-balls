# Minecraft 多主题地图背景

## 目标

为游戏原有“蓝色空白 / 草方块”背景扩展更多 Minecraft 风格主题。每个主题都独立控制三层视觉：

1. **地图内部背景**：按地图格子重复的原版 16×16 方块顶面贴图。
2. **墙体背景**：贴地图外沿一圈的原版方块顶面贴图，仍共享原有的装饰墙、传送门缺口和门洞裁剪规则。
3. **整体视差背景**：地图外的慢速视差图层；可为每个主题单独选择颜色、尺度、视差比例和图案来源。

非蓝色主题仍使用原有“一格装饰外沿”逻辑，所以黑框、顶部/互动文字、底部水印、外侧裁剪、死亡特效和视角适配继续使用现有通道。

## 当前主题

| key | UI 名称 | 地图内部 | 墙体 | 整体视差背景 |
| --- | --- | --- | --- | --- |
| `blue` | 蓝色空白 / Blue Empty | 原蓝色底 | 无装饰墙 | 原始蓝色棋盘视差 |
| `grass` | 草方块背景 / Grass Blocks | 草方块顶 | 橡木原木顶 | 恢复原始蓝色棋盘视差 |
| `sand` | 沙地方块背景 / Sand Blocks | 沙子 | 砂岩顶 | 砂岩顶面贴图复制 |
| `stone` | 石砖要塞背景 / Stone Bricks | 石砖 | 深板岩砖 | 黑石顶面贴图复制 |
| `nether` | 下界岩背景 / Nether Wastes | 下界岩 | 下界砖 | 下界砖贴图复制 |
| `end` | 末地石背景 / End Stone | 末地石 | 紫珀柱顶层 | 紫珀方块贴图复制 |

沙、石、下界和末地的外部视差直接重复对应维度的原版方块贴图，不再使用丑的程序化色块/波浪。草方块的总体视差已经按用户要求恢复成之前的蓝色棋盘样子。所有贴图仍走同一相机位移比例，所以仍保留地图外远景视差。

蓝色背景现在不显示地图内沿墙脚阴影：它没有真实方块墙体，旧阴影在内部呈现成不必要的黑条。非蓝色贴图主题仍保留方块墙体周围的正常阴影。

## 组成

- `Scripts/effects/我的世界/地图背景主题.gd`：单点主题注册表。新增主题时在这里列出 OPTIONS、内部贴图、墙体贴图、可选的整体视差贴图、视差格子尺寸与视差强度。
- `Scripts/effects/我的世界/地图草方块背景.gd`：纯视觉内部/墙体 Sprite 渲染。仍每个普通非传送门地图最多 5 个 Sprite，不为每一格建节点。
- `Shaders/world_outside_checker.gdshader`：整体视差；样式 0 是旧蓝色棋盘，样式 5 使用原版方块纹理复制，1–4 的旧程序图案仅作为备用参数保留。
- `Scripts/world.gd`：把当前设置转换为主题，并把三层应用到地图、外沿、门洞颜色和刷新流程；物理矩形、MapSafetyFrame 几何及原始 TileMap 均不随主题改变。
- `UI/control.gd`、`translations.csv`、`global/translation_catalog.gd`：下拉框动态生成六个选项，并支持中英文。

## 素材来源

新主题使用的方块贴图均提取自官方 Mojang **Minecraft Java Edition 1.21.1 client.jar**；client.jar 下载后以 SHA-1 校验，值为 `30c73b1c5da787909b2f73340419fdf13b9def88`。已有草方块顶和橡木原木顶继续沿用项目内原有原版贴图。

本项目是借用这些原版资源以实现用户要求的 Minecraft 风格；贴图本身不重新宣称成自制素材，仍受 Mojang 版权与 EULA 约束。

专项覆盖：

- 六个主题的 OPTIONS、UI 当前项与中英文翻译。
- 每个主题的内部贴图、墙体贴图、整体视差贴图、着色、格子尺度和视差比例。

- 非蓝色主题的一格装饰外沿、Door 背景色、二转回普通蓝色。
- 地图物理矩形和墙体碰撞位置在主题切换后不变。
- 50×50 地图仍然只靠少量 Sprite 绘制，不产生逐格节点。
- 石砖覆盖层和旧视差回归仍通过。

## 说明与限制

- 外部方块视差仍按标准 16×16 贴图规则复制；这是响应用户要求的 Minecraft 方块式复制，不再随机生成地形图案。
- 已用真实场景和碰撞射线验证标准几何；本轮没有另外准备双客户端联机实测。
- 主题设置照旧是本机视觉设置，不进入联机共享状态。
