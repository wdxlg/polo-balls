# 木剑第四次调整：武器碰撞命中与伤害分工

通过当前 MCP 修改生产 `scripts/characters/我的世界/frontier/wooden_sword.gd`。

## 命中方式

- 完整木剑、剑柄、剑刃都有附在武器 Sprite 下的 `WoodAttackHitbox/WeaponShape`。
- 从现有原纹理的不透明像素提取**凸多边形碰撞形状**，不是大范围圆形/扇形自动结算，也不宣称逐像素精确碰撞。
- 在攻击有效帧，对随挥舞/直刺移动的形状执行物理空间查询；只接受与敌人实际 `hurtbox` 的相交，不再按距离、角度直接扣血。目标可以躲开，挥空不会造成伤害。
- 按武器移动距离、转角和动作进度补采样，减少快速旋转/直刺时穿过目标却漏判。每次攻击对同一受击者最多结算一次。
- 前摇和收尾无伤害；墙体遮挡、友军/同一木剑家族过滤保留。
- 训练攻击区域覆盖层使用同一个物理多边形及其世界变换；碰撞形状与渲染动作共用姿态计算。
- 纹理凸包按世界缓存，随本局释放；不在每帧从 GPU 读取贴图，也不使用会保留整个脚本资源图的静态缓存。

## 默认数值

| 形态 | 满蓄力普通命中 | 击退距离 | 攻击动作与回充 |
|---|---:|---:|---|
| 木剑 | 34 | 12；架招反击 18 | 挥舞 0.34 秒、回充 0.625 秒 |
| 剑柄 | 原伤害 20%，当前实际掉血 7 | 55 | 挥舞 0.34 秒、回充 0.70 秒 |
| 剑刃 | 原伤害 125%，当前实际掉血 43 | 0，不创建击退控制器 | 直刺 0.20 秒、回充 0.28 秒 |

表格伤害为当前场景 Damage 34、满蓄力、无增减伤目标的测试结果；保留原攻击蓄力倍率与架招反击增伤。木剑碰到后续目标仍使用原横扫次目标减伤，但每个目标都必须实际碰撞。

普通移动、不主动追敌不变。耐久仍为 45，攻击每次扣 1，实际掉血每 5 点扣 1（单次 1–5）。最后一点耐久允许本次碰撞动作完成后再断裂。

工作台三秒显现、显现后停靠、双部件接触 2.4 秒合成、任一部件死亡破坏工作台及服务终止，均保留。

## 验证

- GPU 首轮修正后专项 **65/65**，实际伤害 `[34, 7, 43]`。验证三种形态的命中与挥空、出手后闪避、关闭受击箱不受伤、同次攻击去重、真实击退控制器参数、剑刃无击退、普通移动、视觉/物理姿态一致、墙体阻挡、断裂与工作台循环。
- 加入训练碰撞区域检查后的最终 headless 专项 **69/69**；脚本目录 diagnostics 返回 0 项。
- frontier 合同回归 **65/65**；旧距离必中夹具调整为真正接触位置，并等待完整攻击结束后再开始下一次。
- GPU 实战回归 **10/10**，包含实际攻击、断裂及接触重组，同时回归苔藓、坚守者、矿车。
- 首轮测试曾将临时生命设为 10000 而未同步默认生命上限，世界更新后导致受击被截断到 1000，已修正夹具。另将初版静态形状缓存改为世界缓存，复测不再出现该初版新增的资源/Shader/RID 退出错误；仍有原先同类 ObjectDB 退出警告。
- 未做双客户端和长时间压力测试，不宣称全项目零警告。
