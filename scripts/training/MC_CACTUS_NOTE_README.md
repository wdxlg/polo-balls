# 仙人掌与音符盒

已通过用户指定MCP部署到 E:\godot\polo-balls。角色位于“我的世界”分类，已加入资源预热；英文名为 Cactus / Note Block。

## 仙人掌
- 650生命，基础接触伤害16，正常移动速度95。
- 每8秒向上增加一节，最多5节，不加受击断节。生长不改变根位置/底部；实体碰撞、hitbox/hurtbox高度及血条同步改变。
- 只有左、右竖直侧边有接触伤害，同一敌人0.65秒冷却；顶部/底部不造成接触伤害。
- 每3.2秒射刺，手控可用技能触发同一冷却。左右每侧各发“节数×2 + 随机0或1”枚，轻微散射，发射高度覆盖当前植株。
- 刺使用骷髅箭的实际射线/闪避筛选及附着定位基础，原版箭素材缩小染色适配。一次伤害，无击退；命中人物或墙后只作装饰，3秒消失。无持续伤害、处决、拔刺或二次拾取伤害。飞行2秒兜底回收，暂停冻结寿命。

## 音符盒
- 480生命，基础伤害12，正常移动速度100。
- 演奏并轮播完整原曲 Pigstep、Otherside、Cat；玩家讨论中的热门选择，不声称是官方统一排名前三。
- 对实际音频作20ms RMS响度分析、轻度平滑及局部峰值检测；最小峰间隔120ms，用于排除采样噪声，并非固定攻击间隔。
- Pigstep约148.24秒/520峰；Otherside约195.65秒/784峰；Cat约185.34秒/513峰。
- 用实际AudioStreamPlayer2D播放位置消费峰表，峰高影响伤害、音波速度、弧宽、射程、线宽和拖尾。
- 每个峰向最近敌人当前位置发出一道白色弧形波，飞出后不追踪。内侧拖尾逐渐透明；用分段扫掠检测实际受击箱，不是整圆必中，每波每人只伤一次。
- 按发射顺序结算音波（避免高速波超车打乱连击）；一道波至少命中一人算成功。连续成功每次提高0.04倍播放速度，最高1.8倍；一整道波落空即恢复1倍。播放速度也改变音频音高，并非只加快攻击计时器。
- 暂停冻结真正的音乐播放与战斗。无敌时音乐继续演奏，音波落空将重置连击。曲终轮换。

## 素材与复现
最终方块外观从 Mojang Java 1.21.1 客户端原始 cactus / note_block / cube_all / cube 模型、UV和纹理离线光栅化为2D PNG；投影和画框按游戏尺寸适配。运行时没有3D。源码与客户端URL/SHA1在 model_source/source.json；bake_blocks.py 可复现。初次平面纹理拼接为中间版本，不代表最终图片。

唱片来自官方资源索引及 resources.download.minecraft.net，原始音频未修改，SHA1均核对：
- Cat — C418：d1eb3d2e39bf1f6289cfcbca44e1c9bb508b20f0
- Otherside — Lena Raine：a5effd79795773422bb4de85841838f3ad9c216d
- Pigstep — Lena Raine：9ffb1791e8aba8f266a673abec1846c3bf8fb8cc

模型、纹理、音乐保留各自版权，使用原版素材不等于获得公开再分发或商业音乐授权；发布项目时需自行确认 Minecraft 使用规则及音乐权利。未将这些素材标为开源或免版税。

analyze_music.py 可从项目安装的原曲重新生成峰表。峰表以预加载GDScript常量打包，避免导出游戏时漏掉外部JSON。
