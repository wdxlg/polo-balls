# 音符盒第二版与方块左右朝向

已部署。

## 连击
- 取消连击加速：AudioStreamPlayer2D.pitch_scale始终1，音频时钟不乘连击速度。
- 每成功音波伤害倍率+0.06，最高1.9倍；音乐音量由-10dB每次+0.65dB，最高-3dB。
- 音波第一次有效命中即可上报成功；为避免高峰快波超车，仍按发射顺序处理结果。完全落空重置音量与伤害，不重复结算同一道波。
- 伤害增益在发射时写入投射物，已经飞出的音波不会突然随连击变强。原有“音乐峰越高，音波伤害/速度/尺寸越高”仍保留，连击本身不加快波速。

## 朝向与曲目视觉
- 仙人掌、音符盒使用项目Shader左右镜像；优先读取实际velocity，其次direction。上下移动保留上一左右朝向，不旋转本体。仙人掌收缩/弹性放大及底部固定不受影响。
- Pigstep：橙红弧线、金色火星拖线。
- Otherside：蓝色弧线、紫色交织波纹。
- Cat：绿色弧线、浅绿漂浮音符。
- 三者都有内侧渐隐拖尾。附加图形仅视觉，不增加碰撞/伤害或额外节点；飞出的波保存发射时曲目，切歌不改变旧波。
