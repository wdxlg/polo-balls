# 木剑：50 耐久、断剑双部件与工作台修复

已通过用户提供的新 MCP 部署到 `E:\godot\polo-balls`。停止旧运行实例，再重新运行项目；不要用旧实例的热重载状态判断初始耐久。

## 规则

- 初始耐久 **50**。每次成功发动攻击消耗 **1**，空挥也消耗；同一次横扫命中多人不重复扣除。最后一点耐久的攻击仍会完成命中，然后断裂。
- 实际生命伤害按 `clamp(ceil(实际掉血 / 20), 1, 5)` 扣耐久。完全被护盾挡住、不掉生命的攻击不消耗这一路耐久。
- 原来的蓄力斩、横扫和架招反击保留。架招仍减免 65% 伤害，但不再另按吸收伤害重复扣耐久，只对实际掉血应用上述 1–5 规则。
- 耐久归零：原地留下工作台，分为**剑柄**和**剑刃**。剑柄沿用原角色节点，剑刃是独立战斗角色；两者分别受伤、死亡，不共享生命。
- 默认 600 生命上限拆为各 300，剩余生命也拆分，每部分最低 1 点。致死伤害不会凭空生成活的碎片来复活木剑。
- 剑柄挥舞攻击，伤害为原攻击的 35%，满蓄力命中带 18 单位小幅击退。剑刃按实际移动方向朝向，转向附近敌人并刺击，伤害为原攻击的 65%，刺击前摇期间加速。
- 两部分**不主动寻找工作台**。自然碰到自己的工作台后停留治疗，仍可受到外力推动；离开即失去工作台保护。
- 工作台接触范围为台面半径 18 加角色半径，并验证地形视线。接触时标准伤害路径额外减伤 **50%**，每秒恢复自身生命上限 **5%**，使用正常治疗接口、尊重禁疗规则。回血保留小数累计，约每 0.5 秒结算一次，避免大量 +1 跳字。
- 必须同一把剑的两个部件都存活、连续接触工作台 **2.4 秒**，才能重组。离开或死亡重置进度；正常受伤不额外取消有效的接触进度。
- 重组恢复 **50 耐久**，生命为两部分当前生命之和，上限恢复为原木剑上限；不会额外回满血。消耗剑刃及旧工作台，不算击杀，不播放被消耗部件的死亡效果。
- 任一部件死亡后，另一部件仍可在工作台治疗，但无法完成修复。两个部件都不存在时，工作台自动清理。不同木剑的部件不能交叉配对。
