# 唱片机本体连续跟随音乐变形

已部署到生产 `scripts/characters/我的世界/cactus_note/`。

## 修正原因

上一版虽然读取了音乐特征，但仍是在攻击峰事件里更新本体目标；歌曲中没有被选为攻击峰的片段不会推动形体，因此会显得脱节、不够连续。

## 当前实现

- 为六首唱片新建独立的离线分析轨道 `music_shape_features.gd` 与 `shape_{pigstep,otherside,cat,creator,precipice,relic}.gd`。
- 每60毫秒记录一次 `[时间, 高低音形状, 音乐能量]`，共22401个采样点；高音为正、低音为负、静音返回中性。
- 运行时按真实音频播放时钟查找当前/下一采样，并在两采样间逐帧插值；视觉值再用指数平滑，所以不会像阶梯一样只在攻击峰时瞬跳。
- 高、低、响度能量离线分析仍是混合音频近似，不是分轨或乐谱识别；战斗中没有新增FFT。
- 攻击函数不再更新本体形状；命中、miss、叠层、伤害与发射结果也不参与。
- 高音明显变细拉长，低音明显变粗压扁；底边中点始终不动，碰撞体不变。
- 插盘、暂停、死亡或退盘阶段回到中性/冻结；联机继续同步现有本体形状与能量快照。

验证：

- 覆盖六首歌的连续60毫秒包络、每首高低音端点、插值不瞬跳、真实播放驱动本体、更新本体不新增攻击/叠层/音波、底边锚定和碰撞不变。
- 通用 `test_mc_cactus_note.gd` 已同步；模块 GDScript diagnostics：0。
