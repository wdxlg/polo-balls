# 第五轮角色修订

## 活塞
移除“刚黏住就跳过”和“黏附目标一律不受末地烛伤害”两个提前返回。黏附中仍按原伸出行程伤害节奏命中，每个行程防重复伤害；保持原黏附控制器，不为黏附目标创建竞争的推挤控制器。前方其他敌人也正常攻击，前方无人则收回。

## 恶魂火球（本轮确认后的规则）
- 初次发射在地图内：0 次边界穿越机会，碰边界即爆炸。
- 初次发射在地图外：1 次进入机会，穿入后再次碰边界爆炸。
- 确认反打后：重新获得 1 次边界穿越机会。
- 按恶魂发射位置判断内外，而不是按前方 30 单位的火球生成点判断；首次扫掠覆盖该段生成偏移，不能直接生成到墙另一侧跳过碰撞。
- 厚边框、同 RID、窗口外清除、烟雾拖尾及既有内部墙/中立伤害规则保留。

## 守卫者原版纹理
撤除第四轮额外添加的橙色亮芯。直接采样已有原版 guardian_beam.png，沿其原生 UV 方向（U 为周向，V 为纵向）进行二维条带适配、重复与滚动；保留透明纹路，不填一条实心激光。颜色采用守卫者充能调色规律，视觉宽度和重复长度可调整；未改伤害周期或四轴 ±15° 门槛。此为原素材的 2D 适配，不声称完整复刻原版 3D 渲染器。
