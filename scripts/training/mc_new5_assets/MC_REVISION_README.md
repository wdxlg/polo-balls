# MC 角色修正与可复用爆炸

已部署至远端 Godot 项目，2026-09-17。

## 修正
- 史莱姆和恶魂按水平移动方向翻转，保持直立；钓竿本体只左右翻转，钩线和挥剑仍可朝目标方向。
- 守卫者原版模型的 mirrored cube 必须交换 X 侧面，而不只是翻转每张面的 U。修正旧 UV 采样透明区造成的缺面，并保留独立原版眼球。
- 活塞拆为同视角、同机械轴的底座、移动头、连杆和原版末地烛模型。底座不再重复绘制绿色头。初次 ready 即装配正确，避免第一帧尺寸闪变。
- 五个角色接入 MCSounds 原版动作音效变体；生物受伤音默认 45% 概率，死亡单次播放，环境音完整播放后间隔 3–7 秒。大小史莱姆分别使用原版大小音效。音效沿用 GameplayRecord 路由、限流和最多 24 声部。
- 默认音频总线从未识别的 UID 引用改为明确资源路径；统一了两个旧 shader 大小写引用。没有关闭脚本警告开关。
- 黏附开始时停止既有位移控制器，保留真正的其他眩晕效果及其控制锁计数，避免多控制器争抢。

## 可复用 MC 爆炸

资源：`res://scenes/effects/我的世界/MC爆炸.tscn`

脚本：`res://scripts/effects/我的世界/mc_explosion.gd`

```gdscript
const MC_EXPLOSION = preload("res://scripts/effects/我的世界/mc_explosion.gd")

MC_EXPLOSION.spawn(self, global_position, 60.0, {
    "sound": true,
    "volume_db": -2.0,
    "allow_outside": false,
    "seed": 1234, # 可选，固定纯视觉随机序列；省略则随机
})
```

这是纯视觉和可选音效组件，不处理伤害、阵营或击退，因此不会重复扣血。已接入恶魂火球和苦力怕；原有战斗数值保持各自角色脚本负责。

- 使用用户提供的 explosion_0–15，按编号播放；将逐像素放大的 1024 图精确最近邻还原为 32×32，保持相同透明画布，不裁剪或重新居中。
- 主爆炸在指定半径内分散生成，随机比例和白到深灰颜色。
- 小烟雾复用烈焰人的 `MC通用粒子帧.tres` 中 smoke 序列；尺寸显著小于主爆炸，颜色允许全黑。
- 烟雾在 X/Z 平面炸散，具有独立高度、竖直初速度、重力、地面回弹、阻力、深度缩放和前后排序。
- Alpha 保持 1，靠原帧动画消散；结束自动清理。
- 正常爆炸保留地图遮罩裁剪；`allow_outside` 用于恶魂等允许在地图外显示的效果。
- 联机时应在权威端发出的视觉 RPC 回调里每端本地调用一次；该函数不会再次自动联网生成。局部特效容器避开 World 根的 MultiplayerSpawner，且不跟随死亡角色提前销毁。
