# 第四轮修订

## 生产修改
- `slime.gd`：脚底平面中心使用原烘焙 foot=180，而不是贴图 alpha 最下端 202（后者是立体方块底面的前缘）。
- `slime_jump_fx.gd`：计算 Image 到 World 的继承后实际 Z。实景 World=-2，之前所谓后排粒子也是绝对 Z=-2，反而因后绘制盖住本体；现后排/绿圈在实际本体下一层，前排在上一层，随源角色的地面位置判断前后。角色消失后特效独立播完。
- `guardian.gd`：原激光 LINE_TEXTURE_TILE 未启用 TEXTURE_REPEAT_ENABLED，超出第一块纹理后采样到透明边缘。现开启重复，增加不受场景光照压暗的细亮芯；失锁时两层立即隐藏。四世界轴各 ±15°、周期伤害、穿线和刺伤机制不变。
- `fireball.gd`：发射有一次地图边界穿越机会，第二次边界接触引爆；确认反打后重置为一次。只减速、尚未反打的伤害不重置。
  - 厚边框跨多个物理帧只计一次；同一步遇两道边界也正确计数。
  - 不忽略整个 TileMap RID，避免放过同 RID 上的第二道边界。用小半径接触探针避免 point-query 不含表面、ray-query 含表面的精度差造成出墙时多算一次。
  - 保留此前的内部墙规则：原态被内部墙阻挡，中立反弹态可穿内部墙；非墙障碍仍引爆。此次“只能一次”的限制针对地图边界，并非消耗于内部墙。
  - 使用实际火球非透明贴图矩形，经当前相机/Canvas 变换后判定窗口边界：部分可见保留，全部出窗口无爆炸清除。
  - 直接复用烈焰人的 MC烟雾粒子 场景，默认间隔 0.06 秒，另按 8 世界单位间距补粒子；测试每秒 15 个，比烈焰人默认每 0.20–0.38 秒一个更密。烟雾参数可导出调整，仍靠原帧消散、不做 alpha 渐隐。纯本地特效不重复联网生成。
