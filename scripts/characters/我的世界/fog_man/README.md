# 雾中人 / The Man From The Fog

## 接入
- 场景：`res://scenes/characters/我的世界/雾中人.tscn`，由现有目录索引加入“我的世界”分区。
- 600生命、45基础攻击；缓慢跟踪，敌人后方90范围保持0.6秒后打雷，狂暴4秒，结束冷却5秒。
- 仅狂暴攻击改为随机双攻击循环：化作雾团以360速度冲向敌人，穿过敌人身体时造成一次45伤害，同一轮不重复扣血；或完全消失0.38秒后突然在敌人身旁显出完整正面头部并爆发一小圈雾气，对100范围内的敌人各造成一次45伤害；头部按本体头部比例显示，不放大。每轮结束以约210速度后撤0.45秒再随机选择。未碰到/被挡住不隔空伤害，攻击被防御也正常脱离。
- 攻击化雾隐藏整个角色及HUD，由独立的动态雾团和0.32秒短拖尾替代；仍保持狂暴可锁定、可受伤，不触发8%消散代价。新增阶段同步与退出复原；苦力怕雷电放在独立特效层避免随身体隐藏。
- 回归：原机制41项、自动实战9项、突进契约17项、突进GPU6项；自动实战验证随机两种攻击、重复命中和有界雾团，无注入攻击状态。
- 被敌人看见身体采样点至少60%且持续0.3秒：扣最大生命值8%（600血时扣48，可致死），消散2秒后重现。护盾和减伤不抵消被识破代价。
- 重现最多先做6次低暴露候选搜索（每次48点），优先零暴露，失败时选最少暴露；不能落在障碍、角色身上或距敌人125以内，也避开已驱雾区。没有安全落脚点时继续等待，不穿墙强行生成。
- 浓雾潜行不接受自动锁定，但可被范围/飞行中攻击打中；消散阶段没有实体碰撞和伤害目标。狂暴期间可锁定且不再触发被发现消散。

## 显示
- 全场单一共享雾，多个雾中人不叠加浓度；最后一个死亡后渐隐释放。
- 雷击清雾基准半径缩小为180（原300），轮廓由多频角度波形成不规则边缘，并采用约100世界单位宽的柔和羽化带；内部在落雷当帧清空。狂暴结束后3.2秒内边界向内收缩，实际雾片从外圈流向中心；最后0.8秒清雾强度与推挤力同步淡出，收尾平滑无残点。
- 直接实例化苦力怕的 `scenes/effects/我的世界/雷电.tscn`：先播放同一组thunder1/2/3，预警0.68秒后落雷并播放同一组explode1/2/3/4。使用同一音量和视觉参数；落点跟随脚底，落雷信号同时触发驱雾和4秒狂暴计时，不叠播旧雾中人雷声。
- 被发现消散时隐藏整个角色根节点，包含血条、护盾/能量条、眼睛、拖尾和附属特效；已存在的自身飘字立即隐藏，自损飘字不生成，重现后恢复。伤害飘字通过弱引用标记归属，不误删其他角色的飘字。
- `tests/preview_mc_fog_thunder.gd`：19项GPU/状态检查通过，包含复用苦力怕雷电场景、先预警后落雷、180半径、边缘分级透明、外围先恢复/中心仍清空、完整HUD隐藏及重现恢复、攻击化雾隐身时闪电仍可见。
- 雾完全由4张原创透明PNG云团作为独立Sprite2D重叠、漂移、缩放和轻微旋转组成，没有纯色背景。密集雾片叠加产生遮蔽，纹理由 `tests/generate_mc_fog_clouds.py` 可复现生成。
- 雾渲染覆盖摄像机视野并向外延伸380世界单位，不沿地图矩形裁切；视野遮罩通过世界坐标映射，避免Polygon2D的UV单位导致浓淡区域错位。
- 空间遮罩保存驱散历史，新区域约0.7秒渐淡，旧区域约2.2秒回填；转向不瞬间消失/恢复。雾片中心主动向驱散区域边缘退让，位移约0.85秒响应、2.5秒时间常数缓慢回流。
- `tests/preview_mc_fog_clouds.gd` 的13项检查覆盖无背景、缩圈、渐淡、转向保留、慢回填、主动退让和地图外渲染。黑白背景GPU取样：浓雾接近不透，近身圈透过约32%，三角约35%，不再接近完全清空。
- 其他角色身边32范围及前方长180、半宽90的三角视野淡雾；方向取移动速度，静止保留最后朝向。
- 视野遮罩采用墙体射线裁剪，身体发现判定也检查墙体。导航会避让所有角色的淡雾区，包括队友视野与雷击驱雾区。
- 身体40帧原模型贴图渲染，眼睛40帧独立遮罩并叠加光晕；拖尾最多12个、0.28秒衰减。没有额外头顶状态文字。
- 单场最多12个雾中人音效声部，环境耳语共享间隔；暂停时停止计时/音效推进。
- 状态与一次性音效/雷击事件由权威端同步；回归包含远端状态回放，但未进行两台机器的联网联调。
