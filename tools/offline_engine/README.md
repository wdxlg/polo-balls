# 当前状态离线录制专用引擎

## 使用

在项目根目录双击 **`启动离线录制版.cmd`**。它用独立引擎运行同一项目、读取原有用户设置与录制目录。进入对局后，右键录制按钮即可从当时的完整状态继续计算。

如需边修改边运行，可关闭旧编辑器后用 **`启动离线版编辑器.cmd`** 打开项目，避免两个编辑器同时修改同一项目。脚本不会自动关闭任何已有进程。

**旧的运行进程不能热切换引擎。** Steam 原版仍可左键实时录制；它不具备本项目新增的原生接口，右键会明确提示使用上述入口，绝不会偷偷退回“重打上一局”。独立引擎路径：`../polo-balls-tools/offline-engine/runtime/Godot.4.7.2.offline.exe`。

## 行为

- 左键仍录制正在发生的实时对战。
- 右键不调用 rematch/reset，不加载初始布阵，也不复制/重建另一套世界；原来的角色、飞行物、剩余血量、速度、状态、计时器和脚本执行状态继续使用。
- 固定 60fps 游戏时间时钟，逐帧计算、渲染、混音。编码跟不上时等待，不推进下一帧，不按墙钟补旧画面；计算慢只增加等待时间，不延长成片。
- 导出把用户基础倍速规范为 1x，保留角色技能自身的时间覆写；结束恢复用户基础倍速。
- 主窗口只有进度和中止按钮，不再多渲染一份战场；最小化窗口仍可生成真实离屏帧。
- 结束或中止后暂停在已经计算到的状态，可按 Esc 继续；不恢复到点击之前，不在后台继续打未录制的部分。
- 暂停及恢复倒计时不进入成片。退出场景会回收编码线程并恢复原先的引擎时钟、音频、帧率和 VSync 状态。
- 中英文共享一次对局计算和一条音频时间线，文件名仅 `中文_` / `英文_` 前缀不同。

## 原生修改

源版本为 Godot **4.7.2 / ed1daf0bf**，不是替换或修改 Steam 安装目录。`engine.patch` 是可审查、可重建的源码补丁：

1. `Engine.set_recording_fixed_fps()`：仅在会话中切换固定时钟，切换时重置墙钟抖动历史；普通运行不改变原有时间机制。
2. `AudioServer.set_offline_audio()` / `render_offline_audio()`：保持原音频流、解码器及效果器状态，硬件线程停止推进混音，由视频帧精确拉取采样；录制 GameplayRecord 总线，排除 UI。
3. 离线时脚本 `Time.get_ticks_*()` 使用连续的虚拟时钟，防止影子轨迹、冷却、威胁提示等仍按实际计算耗时运行。结束时保留时钟连续性，不能把尚未结束的绝对时间戳冷却突然跳过去。操作系统时钟、日期和引擎内部性能计时不改；编码器超时使用新增 `Time.get_wall_ticks_*()`。
4. 固定时钟模式强制完成离屏绘制，即使窗口最小化；不让物理推进而捕获协程永远等不到绘制。

`build_manifest.json` 记录源码包、补丁与独立运行文件 SHA-256。`GODOT_LICENSE.txt` 保留 Godot MIT 许可；运行目录也保留完整 `LICENSE.txt` 与 `COPYRIGHT.txt`。D3D12 依赖由 Godot 官方安装脚本安装。

## 重建与回退

Windows 下需 Visual Studio C++ 工具、Python 和 Git，手动运行 `build.ps1`。它下载校验固定版本源码，在项目外的工具目录构建，不改 Steam 原版。当前二进制已实际构建并通过测试；重建脚本完成静态/补丁检查，尚未从空目录完整重跑。

项目录制代码通过本地 Git 检查点回退。恢复旧版时也可继续使用 Steam 原版；不应 `reset --hard` 覆盖其他未提交修改。二进制不纳入项目 Git，校验清单和源码补丁纳入。

## 实测边界

离线不是“只算一个胜负数字”：生成完整高质量过程视频仍需渲染每一帧。因此不会固定等四倍时间，但**不保证一定比实时更快**；人物、特效、GPU 读回及双路编码决定耗时。

已验证真实“牛 vs 木剑”的中途血量/位置/速度/对象身份、原生飞行物与剩余计时器、时间戳冷却、用户 3x 倍速恢复、慢计算及最小化时的正常动作速度和音调、暂停/恢复/场景退出。尚未声称穷尽所有角色组合、所有第三方脚本或长达数小时的对局。最多计算五分钟视频时间后收尾；无终局的对局可随时中止并保存已有片段。
