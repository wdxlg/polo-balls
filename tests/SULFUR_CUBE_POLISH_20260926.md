# 硫方怪四形态修订与公共像素圈（2026-09-26）

## 本轮改动

- **TNT**：删除角色内的平滑 `draw_arc`；外圈改为与重锤同一公共三层像素环。新增 16% 不透明度的红色填充盘，半径为 `TNT_RADIUS * (1 - fuse_left / TNT_FUSE_SECONDS)`，从中心单调扩展到爆炸边界。外圈半径仍为 80 世界单位、引信仍为 2.4 秒，未改爆炸伤害。视觉进度读取真实引信，不另跑独立计时器；暂停、爆炸、换形、死亡和角色删除均不会残留旧圈。
- **公共接口**：`pixel_arc.gd::draw_ring()` 统一重锤三层宽度/透明度，原 `draw()` 继续兼容已有半圆/弧调用。`draw_disk()` 复用同一缓存扫描线算法，以内半径 0 的环画填充盘；没有另写平滑圆或第二套像素算法。重锤已改调用 `draw_ring()`，保留其既有调色板、扩散、衰减、碎屑和射线逻辑。
- **铁块**：复用 `ball` 的定向重力积分和支撑碰撞，原生向下加速度 1200；常态主动移动仅 X 轴。W/S 不产生上浮或虚构横向输入；静止/眩晕仍下落，暂停不推进。进入/退出形态保存/恢复此前的重力模式，退出清除本形态下落惯性。单次跳砸、穿过角色但不穿地形和原有下表面伤害保留；手控跳砸从鼠标位置取落点，不再自动选 AI 敌人。
- **紫水晶**：去掉旧的锥体与顶部小贴片组合，用现有原版 `amethyst_cluster.png` 的双交叉面模型，根部放在内部方块内，由内向外倾斜刺出。身体与投射体都实例化 `sulfur_amethyst_crystal.gd`；发射 RPC 携带每根晶体当帧的 3D 变换、原版纹理模型尺寸、相机和 2D 投影变换。射出不再换成 `amethyst_shard.png` 物品图。投射体原点仍是晶尖，完整模型从同一位置连续移出，不变形/变大/换图。扩大 3D 相机取景但反向补偿显示倍率，保留身体世界尺寸并避免刺尖被 viewport 裁掉。
- 晶体再生增加 0.24 秒由内向外生长；未长出期间不产生晶尖接触伤害/威胁。修复投射体 `get_ai_hazard_info(receiver)` 参数契约，实际开启设置中的威胁显示时不再因无参函数报错。身体和飞行晶体仍按各自晶尖机制提供威胁，而不是把整个贴图外框当伤害区域。
- **冰**：原逻辑只让父类反射 `direction`，随即恢复旧朝向，且未反射 `_slide_velocity`，导致持续朝墙推。本轮沿实际所有碰撞法线反射持久滑行速度，包含墙角；保留 0.18 秒反弹动量，之后正常接收转向。手控原始 WASD 输入不会被改写。

## 手控顺序

- 左键：原短冲刺；铁块为单次跳砸。保留原 Attack 冷却。
- 右键：原随机换块。保留原 Skill 冷却；点燃的 TNT 不能逃避自身爆炸。
- 紫水晶形态额外中键：四晶齐射，按自身 2.4 秒蓄好 / 0.8 秒再生节奏检查；手控期间不自动齐射。没有删除原左键冲刺，也不重复绑定动作。
- TNT 引信和碰撞效果仍是被动；纯弹道晶体不是可 C 选择的独立角色。

## 素材来源与范围

本轮没有引入或生成新音画素材。使用项目已有 Minecraft 原版晶簇纹理；来源、JAR 路径、版本和许可沿用 `Images/characters/我的世界/sulfur_cube/source/REDESIGN_SOURCE.json`。双交叉面是引擎中对已有素材的组合，不是重新绘制原版纹理。像素圈是现有重锤绘制器的公共化，不冒充原版游戏贴图。
