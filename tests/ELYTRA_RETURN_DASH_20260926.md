# 鞘翅：地图外软回航、迎敌穿刺与命中加速

## 用户要求和明确选择

- 鞘翅重锤、鞘翅长矛、鞘翅重锤长矛不要离开地图太远，飞出一段距离后自己想回来。
- 只给**鞘翅长矛 / 鞘翅重锤长矛**增加朝向敌人时直接加速穿过的技能；打到人还要加速。
- 用户通过选项明确选择组合型：**先穿过，命中继续提速，穿越完成后再弹起接原重锤连砸**；普通攻击的弹起流程不改。不是冲刺命中立刻弹起，也不是取消组合型连砸。

## 实现和默认参数

### 三种角色共用软回航

`鞘翅重锤.gd` 是三种角色已有的飞行基类，本次只在这一个运动积分链中增加回航优先级，不新建一套移动器。

| 参数 | 默认 |
| --- | ---: |
| 地图外回航距离 | 96世界单位（默认16单位地图约6格） |
| 速度前瞻 | 0.25秒 |
| 返回内部的滞回距离 | 24世界单位，窄区域按尺寸缩小 |
| 回航最低转向角速度 | 8弧度/秒 |

- 从角色所在World2D的祖先查真实地图提供者，复用真实地图矩形及巡航缓存；没有地图提供者时不凭空把世界原点当地图。
- 用当前位置和按速度预测的位置决定是否回航；回到真实地板内部、未来位置也已进地图再退出回航，避免边界抖动。多岛的外轮廓用于限制，返航落点取实际支撑区域，不把地图总中心的空洞当回航点。
- 回航优先于向外继续追击/烟花推进；取消向外的剩余烟花燃烧，保留当前动量按角速度转弯。太远的连砸跃起会结束本轮机会并交还滑翔回航。
- **没有瞬移、坐标钳制或硬围墙**。保留越界救回/淘汰豁免、身体不被墙阻挡、hurtbox正常受击。角色被击退或处于控制状态时仍遵循原受击限制，软回航不是绝对位置上限。
- 手控时不抢走WASD方向，玩家可以主动飞出回航范围。

### 两种带长矛角色新增主动穿刺冲刺

复用 `鞘翅长矛.gd` 的真实矛尖连续扫掠、原伤害计算、接触去重、命中加速和原生烟花/残影；没有另建第二个碰撞伤害层。

| 参数 / 行为 | 默认 |
| --- | --- |
| AI条件 | 敌人在前方±14°、距离16–240；冷却就绪且可以攻击/使用技能 |
| 冲刺冷却 | 1.8秒，激活时读取当前 `Skill_Cooling` |
| 起步速度 | 至少560，或现有速度+220，受当前飞行上限约束，不为了技能降低原有高速 |
| 持续 | 0.45秒，仍与目标重叠时最多增加0.30秒清出时间 |
| 命中加速 | 沿用原穿刺每次有效接触+150；普通低速顶击仍+60 |
| 最高速度 | 沿用 `maximum_flight_speed`，默认900，不无限叠加 |
| AI越界保护 | 预计冲刺出口过于靠外时不发新冲刺；回航可以中断正在进行的冲刺 |

- 伤害读取**当前攻击**和本次扫掠进入时的实际速度，再奖励加速；后面的敌人可使用前一次命中获得的速度。拒绝伤害、友军、同一段重叠、死亡或远端副本不凭空奖励速度。
- 冲刺锁定起步方向；普通重力/阻力/速度上限和飞行媒体仍沿用原体系，没有额外的穿后扣速。
- 组合型保留每个实际矛尖命中的原冲击；冲刺期间只挂一次待发连砸，**不立刻起跳打断穿越**。正常完成后启动一次原连砸链；空冲、拒绝伤害不生成待发起跳，眩晕/死亡/禁攻/回航取消待发。普通非冲刺接触仍立即按原流程冲击、弹起。
- 普通重锤角色没有新增穿刺技能；纯长矛没有获得重锤连砸。

### 手控、威胁与复制

- 两种带矛角色左键 `controlled_pierce_dash_action`、右键原 `controlled_skill_action`（烟花）；新招替换旧空实现的Attack槽，没有把常态矛尖接触重复绑定。鼠标负责冲刺方向，WASD变量不被改写；手控期间AI不自动发冲刺/烟花。
- 原伤害红白几何仍是实际矛尖及组合型命中条件冲击圈；蓝色区域改为真实的前方激活扇区，不再把伤害圆冒充检测。冷却、冲刺、禁用或删除时检测区清理，组合跃起显示原真实落地圈。
- 给各实例复制一份既有 `SceneReplicationConfig`，保留原位置/外观/队伍等全部属性，仅附加飞行速度、回航、冲刺阶段/时钟和连砸阶段数据；不修改共享PackedScene配置资源。只有权威积分移动/加速/结算，客户只读复制状态；晚加入能拿到正在进行的速度和阶段。
- 原烟花尾迹挂在角色自己的父节点/World2D，不串到其他网络子世界。没有新增或重绘美术/音频素材。
