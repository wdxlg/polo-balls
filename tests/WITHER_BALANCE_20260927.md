# 凋灵：移除玫瑰，头弹50 / 波及25 / 冲刺100

2026-09-27，用户明确要求的新规则。此前玫瑰与旧伤害数值仅为历史，不再作为当前角色行为。

## 改动范围

- 删除凋灵的玫瑰预载、生成计时/参数、AI种花、手动种花、生成方法以及头弹爆炸转化花朵的遍历。生产角色脚本不再有rose引用，不是把冷却设成很大或只隐藏花。
- 移除的是角色技能。历史 `rose.gd`、原版图片/声音及分类登记保留，供旧的独立资产测试引用；当前角色没有创建它们的入口，没有删除其他角色或共享资源。
- 头弹 `DIRECT_DAMAGE=50`、`SPLASH_DAMAGE=25`；冲刺 `CHARGE_DAMAGE=100`。保留统一 `own_attack_damage(base_amount)`，公式为当前 `attack_damage(base_amount / 75)`，不写死最终扣血。场景基础攻击仍75，不改角色生命或其他属性。
- 直击目标只结算50，不再额外叠25；同次爆炸内其他敌人结算25。原64爆炸半径、凋零状态、原阵营/遮挡/减伤、权威结算及击退不变。冲刺仍每轮对每名敌人一次，速度325及破障规则不变。
- **觉醒爆炸是另一招，仍为基础45**；信标、持续凋零状态及刚加入的头弹/冲刺原版烟雾均保持。
- C手控按现有动作列表约定只保留两项：左键头弹，右键冲刺。原第三动作冲刺前移，中键不重复绑定；保留瞄准/蓄力/冷却/暂停/眩晕/权限限制，WASD不被瞄准覆盖。
- 角色提供实时属性驱动的中英文盔甲架介绍，移除玫瑰并列出当前直击/波及/冲刺数值；World旧摘要同步修正。
- 头弹威胁使用实时50系数，冲刺威胁使用实时100系数。实际开启威胁显示时发现头弹原 `get_ai_hazard_info()` 不接受公共分析器传入的receiver，已改成可选receiver签名，兼容原无参调用；不改分析器、不新增伤害体。

## 分类与复用

沿用公共登记：凋灵是character；skull是ranged/projectile；冲刺是角色真实身体扫掠；爆炸是原普通范围结算，不当成火焰。头弹/爆炸附加原wither状态，不修改状态刷新/等级/周期。

- 头弹：碰撞到敌人/障碍后原范围筛选、每目标一次；source WeakRef、原Team/友伤、同World2D候选与视线规则保留。弹体不新增可控/反射/阻挡能力；源死亡/到期/命中删除，烟雾仍走共享有限寿命与预算。
- 冲刺：原42半径扫掠、蓄力0.45秒、12秒冷却、地图安全墙及破障管理器；live攻击倍率与威胁使用同一常量，命中集合防止一轮多次伤害。
- 玫瑰阶段：从当前角色动作图中移除，不制造新状态或纯视觉替代。
- 公共 `own_attack_damage`、`impact`、普通受击/原版命中音效、状态/爆炸和粒子实现复用。静态注册审计277场景/601运行脚本，missing/stale/invalid均空；无新增运行脚本或素材。
