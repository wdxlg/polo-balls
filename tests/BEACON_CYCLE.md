# 信标核心发光、移动与光柱周期（2026-09-24）

## 当前约定

信标仍由凋零半血召唤，有独立 180 生命、持续重力与真实碰撞，不加入独立选角。正式激光 **5 秒，每 0.1 秒 6 点，50 跳基础 300**；这些数值不因本轮视觉修正改变。

2026-09-24 视觉要求：**激光发光，从玻璃壳里面的蓝色方块发出，并贴合蓝色方块的大小和形状**。不能再以玻璃顶面作为发射口，也不能为了旋转视觉让柱体的四角脱离内部核心。

2026-09-25 时序修正：随机效果在**光柱正式发射的瞬间**给凋灵，而不是等 5 秒发射结束才给；详见下方「增益触发时机」。

## 原版外观与发射口定位

- 使用官方 Minecraft Java 1.21.11 的 `models/block/beacon.json` 与 glass / obsidian / beacon 三种材质，保留完整玻璃壳、黑曜石底座和蓝色核心。模型、URL、客户端 SHA-1 及资源 SHA-256 见 `Images/characters/我的世界/wither/beacon_block/SOURCE_MANIFEST.json`。
- 烘焙入口 `tools/minecraft/bake_beacon_block.gd`：256×256 正交相机、size=1.85、观察方向 `(2,1.6,3)`，裁剪后为 196×208。运行时最近邻采样；不新增每个信标独立 3D 视口。
- 身体仍宽 62、高 66、常见世界缩放 0.2，实体碰撞和角色生命不变。
- 新 `beacon_emitter.gd` 从原版内部核心 `[3,3,3]→[13,14,13]` 的模型坐标计算投影。核心顶面是 **Y=14**，不是玻璃的 Y=16；边长为 **10**，不是玻璃的 16。
- 投影沿用烘焙相机与每模型单位 `256/1.85/16` 像素，并使用实际身体世界宽 / 196 缩放。典型世界身体宽 12.4 时，发射截面宽约 **7.59**。不把烘焙图外框中的透明 padding 当成玻璃尺寸。
- 光柱底面四个角逐一对应蓝色核心顶面的四个角。`beam_origin()` 是其投影包围盒下端，用于真实射线/矩形；源中心和角点由统一模型投影计算，不再复用蓝圈的玻璃顶面位置。
- 光柱绘制在原版方块图之前：前玻璃边框及实体核心能遮住内部光柱，看到的是从核心顶面穿过透明玻璃向上发光，而不是盖在玻璃外面的白条。

## 发光与立体形状

- 正式柱体保持与蓝色核心一致的方形透视，绘制不同明暗的两个可见侧面。**取消上一版整个柱体旋转**，避免底面角点与静止核心分离；原版像素贴图仍在各侧面纵向重复、按游戏时间每秒 0.2 滚动。
- 柱体稳定宽度精确等于核心宽度，不再是玻璃身体的 90%，也不再用仅占 68% 的窄内芯充当真正发光部分。材质保留侧面明暗和像素纹理，并增加自发光亮度。
- `beacon_glow.gd` / `mc_beacon_glow.gdshader` 是独立 **blend_add** 柔光层，形成柱体两侧光晕和源头亮光；不是仅调整纹理颜色后声称发光。核心顶面与两个可见侧面也有对齐模型的加法发光叠层，不涂亮黑曜石底座或整块玻璃。
- 柔光是视觉 bloom，不是新增有阴影的动态场景灯。它不登记伤害、威胁或碰撞。伤害矩形取实际柱体的动态包围范围；旁边柔光不扩大判定。
- 启动时柱体仍会快速扩大、弹性回落，但**底面最大仅为核心顶面**；上方允许原有 116% 短暂扩宽，稳定后回到 100% 核心宽度。缩小/淡出时底面绕核心中心收拢，不能滑向某个玻璃角。

## 游戏时间与伤害

1. **预备 0.6 秒**：细线、逐渐加强的精灵颤抖、核心逐渐发亮；只抖外观，不抖物理体或激光方向。横向主动速度平滑从 100% 降到 50%。
2. **正式发射 5 秒**：始终正上方，发射时继续横向移动。前约 0.08 秒上方扩宽后回弹；稳定截面与核心相同，射线被实际地形截断。
3. **最后 0.35 秒**：完整柱体收细、透明度降到零，柔光一起消失；速度平滑恢复到 100%。
4. **正式发射瞬间**给凋灵一次既有随机增益；5 秒光柱结束后进入 10 秒间隔，不再重抽或刷新。信标死亡清除增益；持续重力、真实墙面阻挡与移除平台后的下落保留。

每轮实际伤害采样 `0.05, 0.15, …, 4.95`，50 次，每次直接传整数 6，继续走已有 MC 有效伤害和音效入口。300 是无修正且全命中的基础值；增益、防御、格挡和离开柱体仍影响实际结果。

长帧按物理子步、阶段边界和伤害时间点分段，不是在长帧终点补打一串。动态伤害矩形与实际启用的 hurtbox Shape2D 相交；伤害、威胁和柱体宽度共同使用核心尺寸。伤害遍历保留对已释放缓存项的有效性检查。

动画、UV 和阶段使用游戏时间，暂停不继续滚动/扩散。死亡隐藏核心光和柱体；删除信标时其视觉子节点随之释放。2026-09-24 视觉改版当时没有改录制、增益、伤害音量或凋零护甲；之后的增益时序调整见下节。
