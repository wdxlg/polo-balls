# 凋零头弹拖尾 / 鞘翅重锤连击提前重置修正

2026-09-27。仅本轮局部更新，保留共享工作区的其他未提交工作。

## 实际根因与修正

- 原 `鞘翅重锤.gd::_update_flight` 一旦 `_map_return_aim` 触发，直接调用 `_end_missed_rebound`，将高度等级和伤害倍率清空，再切普通滑翔。组合型继承这条路径，因此不是命中计数本身失效，而是**命中后的上升途中被地图回航误判为砸空**。
- 相同受控场地、生产角色和真实伤害入口：修改前，两种带锤角色先成功砸中一次，随后第4个60Hz更新就清零；此时仍向上飞，y速度约−341，根本没到下一次落砸。基线10项中4项失败。
- 修正放在共享父类，不复制组合型的运动逻辑：回航方向参与原连砸的子步转向、重力和真实落砸扫掠，角速度保留地图回航参数；不传送、不钳坐标、不清除已命中进度。原有效命中继续递增、真正空砸/拒绝伤害/一次尝试超时仍结束连击，基础打断/死亡清理不改。
- 修改后，同样场地两者都在200个60Hz更新内完成4次有效砸击，进入第5级、倍率29.6；并验证高度封顶后倍率继续增长、改变实时攻击后下一砸使用新属性。
- 不更改带矛角色的“先穿过、命中继续加速、完成后再起跳”顺序；回航仍可取消**尚未开始的穿刺后待发连砸**，与保留**已经进行中的连砸**不是一回事。C手控/烟花/普通长矛沿用原入口。

- 头弹6单位间距、身后6单位、8像素宽、0.5秒寿命，复用 `smoke_particle` 和已有末影粒子的运动/淡出/暂停/清理；每次至多48采样点，所有烟雾共用256枚上限。

- 真实碰撞时只为**到接触点的已走路径**发烟，不画穿墙的未走部分；不改弹速260、寿命4秒、碰撞、原爆炸/状态、友伤策略和伤害入口。
