# 监守者高伤反馈与激光/普攻互斥

- 修复原因：旧 begin_melee 只检查 sonic_left，未检查0.5秒 sonic_recover；收招动画优先级又高于普攻，因此出现“无动画但普攻伤害打出”。
- sonic_attack_busy统一覆盖蓄力pending、计时、收招、仍存活的自身sonic波。自动/手控/Attack入口、release_melee最终结算均守护；遗留普攻pending会清空。
- 保留已提交激光不可被眩晕/击退中断的机制、实际波扫掠、穿墙穿盾、原伤害和击退。暂停仍冻结计时，死亡清理。
- 高伤害镜头：通用生命setter已经提供震动/闪白/粒子，不重复生成。监守者实际命中>50时，额外调用World现有request_damage_focus/request_heavy_hitstop，视觉参考血量上限200。这样96/144实际伤害面对高血量目标也有推镜和顿挫，伤害越高反馈越强。
- 共享现有镜头缩放上限、同帧最强合并、冷却、画外过滤、用户开关和联机慢动作限制。只有真实扣血才补反馈，护盾/免疫/减伤后的低伤不伪造高伤。
- 用现有命中音效RPC携带实际伤害和参考血量，使远端能走同一视觉入口；尚未双端联机验收。

验证：focus_lock24、unbroken18、sound75、no_stun12、burst19，共148项断言通过。新专项包含真实近战/激光命中推镜、强度递增、镜头上限和冷却、免疫/减伤/开关、蓄力/收招/飞行禁普攻、过期回调零伤害及结束后恢复普攻。旧unbroken测试在第二个独立用例前清理上一个冻结的测试波，不再强行越过飞行互斥。
