# 凋零半血护甲与信标（2026-09-24）

## 确认的范围

用户选择：信标**仍由凋零半血召唤**，不新加到独立选角列表。保留 180 生命、阵营/召唤者关系、每次光柱结束给凋零一次随机增益、信标死亡清除增益。主动移动只能沿 X；Y 由重力及真实物理支撑决定。

## 修改

- 护甲不再是静止的蓝色覆盖层。使用 Mojang 原版蓝/白护甲贴图与 render controller 中的两种 UV 流动：蓝层每秒沿 UV 对角线推进 0.2；白层横向余弦流动、纵向每秒 0.2。两层仍跟随真实六骨骼姿态。
- 能量层改成透明叠加，使用最近邻采样；模型 UV 按原版 geometry 声明的 64×64 图集坐标归一化，而不是按实际 PNG 高度误归一化。
- 独立 3D 视口由 192×192 提升到 384×384，补足中央头部和膨胀护甲边缘的相机余量，并补偿精灵缩放，保持模型的世界尺寸不变。不是凭空添加高清纹理，仍保留原版像素。
- 信标仍是有独立血量的 CharacterBody2D。用完整身体的连续扫掠碰撞替代手改坐标和固定 20px 射线落地；每步重新受重力作用，平台移走、离开支撑后会继续下落；激光期间也不悬空。X 移动不会穿过薄墙。不会复制铁砧的主动跳砸攻击。
- 光柱从信标真实身体顶部**固定朝正上方**，到地图顶部或最先遇到的实体地形处停止，不再转向敌人。保留 0.6 秒预警、1.5 秒发射、每 0.5 秒 12 伤害的周期。
- 复用已登记来源的原版 Java `beacon_beam.png`，纵向重复/滚动纹理，白色核心和淡外层；核心投影随时间变化，射线方向始终向上。视觉节点使用世界单位，不受信标角色默认 0.2 缩放影响，否则会出现“画面长度只有伤害范围 1/5”的问题。
- 护甲和光柱动画使用角色游戏时间，不用着色器墙钟 `TIME`。暂停时纹理不自行流动。
- 预警通过蓝色检测显示注册，预警危险信息当前伤害为 0；发射时注册真正 12 伤害的线段。绘制/伤害/威胁共用顶部起点、截断终点和半径 7。停止、死亡、删除以及关闭威胁显示均清理。
- 信标视觉状态同步补充落地/激活、预警/发射和光柱终点；**本次没有进行双客户端联机实测**。
