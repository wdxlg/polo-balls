# 史莱姆死亡时的落地冲击（2026-09-25）

## 行为与边界

- 大、中、小三阶段死亡时，复用**原有落地**的绿色地面冲击环和原版 `slimeball.png` 粒子；不制作新图片、不调用泛用 TNT 爆炸。原有 Minecraft 史莱姆死亡声、默认角色死亡声、倒地/烟雾与大→中→小分裂保留。
- 生命实际降为零的同步回调立即结算一次死亡冲击，先于下一帧死亡状态/分裂/胜负轮询；直接 `Die()` 也有一次兜底。重复 `Die()` 或重复收到视觉 RPC 不重复伤害、不重复生成死亡特效；仅权威端伤害和击退，复制端只接收可视事件。
- **范围与伤害复用落地判定**：三个阶段中心半径分别为 `32 / 21.5 / 14.5` 世界单位，考虑目标本身碰撞半径；从冲击中心到目标须无遮挡，使用现有 `slime_enemy()` 排除队友和同家族史莱姆。基础落地伤害分别为 `44 / 22 / 9`，以死亡史莱姆的**当前 `Damage`** 经 `attack_damage()` 得出本次攻击，再由受击者现有 `receive_positional_damage()` 结算护盾、减伤等。未产生有效伤害／护盾损失就不施加击退。
- 有效目标沿死亡冲击中心**向外击退**：大／中／小分别 `28 / 19 / 12` 单位，速度 160，复用 `target.apply_knockback()` 的公共碰撞与控制器。恰好在中心的目标也有水平后备方向。普通落地仍然是原来的伤害＋减速，起跳仍然是原来的伤害＋轻击退；死亡时不叠加落地的减速。
- 空中死亡以 `ground_point()` 为**视觉与命中共用中心**；空中的威胁显示补充对应的地面圆形区域，地面死亡与原有落地圆形区域重合。死亡粒子与活体跳跃粒子使用同一 `slime_jump_fx.gd`，但死亡粒子不归已死节点的清理数组管理：角色释放及战斗停止后继续短暂播放，并在约 0.7 秒动画结束时自行回收。普通起跳／落地粒子仍在主人死亡时立即清理。
