# 凋零/信标音效：场景生命周期 add_child / play 红错修复

2026-09-27，针对用户截图 `audio.gd:32` 与 `audio.gd:35` 两条红色运行错误。

## 定位与修复

准确入口为 `scripts/characters/我的世界/wither/audio.gd::play`，不是其他同名audio.gd。它被凋灵与信标共用；信标在 `_exit_tree` 中对仍发射的光柱调用 `beacon_deactivate`，此时父场景的子节点列表可能被锁定。

旧实现先创建AudioStreamPlayer2D，直接向current_scene add_child，再play：父节点锁定时挂载失败，随后对树外节点播放再报第二条错误，还留下孤立播放器。新的生命周期夹具在子节点_ready及_exit_tree均复现与截图相同的行号和两条错误；脱树调用另暴露get_tree空指针错误。

修复集中于已有共享音效入口（一个运行脚本）：

1. 先检查source有效且在树中，再访问get_tree，拒绝无效事件/已排队删除的父场景。
2. 将**创建→挂载→设置世界位置→播放**完整步骤延后到安全消息队列，不是只延后add_child、随后仍立即play。
3. 保存原SceneTree/场景的WeakRef与事件/世界坐标值，执行时复核原场景仍在原树中、未待删除、仍是current_scene；不把旧声音重定向到新场景。
4. 检查通过后才分配播放器，取消请求不会留下树外节点。正常死亡/退出音不要求source继续存活，避免删除人物同时吞掉尾音。
5. 保持原OGG、0dB、1800距离、位置、音调默认值与公共音频总线管理；finished后一次性queue_free。未增加重复播放、限流或静音，未改信标循环嗡声、伤害、粒子或录制实现。

该组件是已登记的纯音频表现，无伤害/碰撞/威胁分量；原本的权威事件/RPC调用方不变。未将其他具有返回播放器/声部预算等不同合同的音效类全局迁移。
