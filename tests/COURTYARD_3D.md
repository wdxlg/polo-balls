# 真实 3D 庭院背景（2026-09-26）

> **已按用户要求移除。** 本文以下仅为历史记录，不再提供庭院选项或运行资源；旧键安全回退蓝色。当前说明、删除/回退范围与 GPU 回归见 `SUMMIT_LIGHTING_CLOUDS.md`。

## 使用
设置 → 参数 → 背景选择 → **3D 庭院（立体背景）**，内部键 `courtyard3d`。新增第七项，不替换六种旧背景，不强制修改用户当前选择。正在运行的旧进程需重新启动游戏后选择。

## 实现范围
- `scripts/effects/courtyard_3d.gd` 创建真实 `MeshInstance3D`：战场石砖地面及岛屿地基、下沉水池、场外石英岸台、四角立柱、草地与分层树木。全部放入同一个 3D 世界，接受真实方向光与投影；没有以预渲染背景图冒充立体场景。
- 复用地图立体墙渲染器的 Camera3D、实际岛屿/门洞几何、最终画布同步和防像素吸附抖动的合成材质。旧二维地面在新三维地面下作为兼容底层；可见庭院地面为三维网格。新背景不创建任何物理体、不更改角色/地图碰撞或伤害逻辑。
- 地面坐标对齐现有二维战场；正常游玩仍为俯视。场景本身可从任意相机角度渲染（已拍摄斜角验证图），**本轮没有开放自由旋转战斗视角，没有把二维角色改成三维角色**。
- 水面使用原版 water_still 逐帧图集，游戏暂停时停止动画；属于有光照的空间平面，不是流体模拟或实时平面反射。
- 仅庭院禁用重复的第二路接影视口，因为它的三维地面直接接影；切回五种旧方块背景恢复旧投影，切蓝色停掉三维渲染。切换/重建时旧庭院立即从树上移除后释放。
- 树木/柱子在战场外，仅装饰，不妨碍真实地图门洞。多岛之间的水也仅装饰，不代表新增可行走或游泳区域。

## 原版素材
新增 `Images/backgrounds/courtyard3d/{quartz_block_top,oak_leaves,water_still}.png`，来自 Minecraft Java 1.21.4 资源镜像；原始 URL、SHA256 和权利说明见同目录 SOURCE.json。使用原图，未生成/重绘替代素材。其他草地、石砖、树皮复用项目原有资源。Mojang/Microsoft 原版素材不能宣称可自由再分发。
