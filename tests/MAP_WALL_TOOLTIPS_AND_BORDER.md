# 非蓝色地图去黑框与药水/附魔框遮挡（2026-09-26）

## 当前规则与实现

本篇取代 `MAP_WALL_FEEDBACK_LAYERS.md` 的墙 Z=90 方案；那一版仅覆盖了 91–99 的战斗信息，**没有覆盖绝对 Z=-3 的药水/附魔框**。

- **蓝色地图保留原黑色边框**；grass / sand / stone / nether / end 不再生成额外的黑色 Line2D 外框。原版方块纹理自身的暗色像素、接触阴影和真实地影不是这条外框，不抹除。
- `World::_add_map_border_segment()` 对五种方块主题直接返回。共用入口也覆盖旧的岛屿边框调用；刷新原本就会清理旧线段，所以来回切蓝色、切地图或开关门不会残留旧外框。传送门原有的方块主题隐藏线框逻辑保留。
- 墙从绝对 90 改为 **绝对 -4**，地影仍为绝对 -4。正确顺序为：**地面 -5 → 墙/地影 -4 → 信息框 -3 → 背景取样 → 人物与普通战斗对象 → 地图外遮罩回填背景**。当前 World 自身为 -2，BackBufferCopy 的相对 0 最终为 -2；不是绝对 0。
- 墙与信息框都在 `MapClipBackBuffer` 之前进入背景快照，外遮罩回填时自然保留墙和信息框、擦除越界前景。**不抬高药水/附魔框，也不把它们移回高层 CanvasLayer**；人物、投射物、障碍物仍可盖在框上。
- 删除墙与外遮罩同 Z 时的节点重排逻辑；不再依赖墙必须排到遮罩后。未改信息框、录制镜像、伤害跳字、血条、碰撞、安全墙、门扇或公共战斗实现。
- 0.4 格无缝低墙、原版材质、真实短影、昼夜循环、精确坐标合成、最终帧相机同步保留。
