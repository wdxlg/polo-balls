## 当前机制

### 删除的功能

- 雪傀儡不再掉一个完整南瓜实体到地上，也不再吸雪/堆雪造人、生成小雪人。
- `mini_spawn_settings`、`snow_field.drop_head/_land_head/_spawn_mini` 等入口、构造状态/RPC、落地南瓜绘制器和小雪人场景已移除；对应预热、分类登记及手控索引同步退役。
- 半血碎裂产生的是**短暂纯视觉方块碎片**，不构成可交互南瓜、雪块或召唤材料，不消耗普通/环境积雪。
- 原普通雪径24单位、融成12单位无害小片的8/4秒寿命，环境雪真实方块尺寸/永久性，寒冷免疫、积寒、冰壳及雪球普通命中/轻微击退保留。

### 连射

| 参数 | 默认 |
| --- | --- |
| 概率 | 每轮有效攻击独立10%，不是每颗雪球再抽一次 |
| 数量 | 20颗，首颗真正生成后再排19颗 |
| 间隔 | 每次0.05–0.10秒独立小幅随机，整轮约1.5秒 |
| 散射 | 每发相对当前瞄准方向随机−15°至+15° |
| 普通攻击冷却 | 保留2秒，连射时继续计时 |
| 普通战斗数值 | 360生命、9攻击、80速度不变 |

- 普通未触发的一轮仍是一颗雪球；进行中的连射不能被长按或重复调用嵌套成多轮。
- 每颗都使用原雪球场景/接触判定，并在发出时读取施术者当前攻击属性，保留Team/Master、普通直击、22积寒、8击退及原受击限制。
- AI连射跟随仍有效的目标位置；手控跟随鼠标瞄准。目标失效则沿最后瞄准点完成已经提交的这一轮，不额外抽签；雪球仍按原墙体/角色接触规则运行。
- 暂停冻结攻击/发射时钟；眩晕、禁攻、禁伤或死亡取消未发完部分。权威端独立RNG决定概率/间隔/方向，客户端只接收实际弹体，不自行重抽或额外结算。
- 原发射音效按本次实际流/音高时长限流，防止连射重叠或不断截断同一声部。没有生成替代音效。

### 首次半血碎头及下一轮保证

- 接入实际掉血回调，生命严格高于50%仍戴头；首次到50%及以下时原佩戴南瓜碎裂一次，换成原版露脸视图。
- 使用公共 `block_fragments.gd::spawn_texture`，传头部原版贴图、实际头部中心/尺度、权威种子与本战场父节点；各端产生相同短暂方块轨迹，没有另一套粒子模拟器或隐藏伤害。
- 武装 `force_next_burst`；只有下一轮**真正成功发出首颗雪球**才消耗。越界瞄准、遮挡、冷却等无效尝试不会吃掉保证。
- 若半血发生在当前连射中，保证留给再下一轮；完成当前轮不能清除它。回血后再次掉过半血也不长回/重复碎头。
- 头部/保证/连射进度使用带修订号的可靠关键状态及原视觉同步；旧包不能长回南瓜、重开已结束连射或重新武装已消费的保证。晚加入不重放已经发生的碎裂。

### 手控与真实威胁

- C手控仍只有左键原Attack入口，按同一10%和半血保证规则；连射是攻击模式，不凭空给右键绑定一个绕概率的“必连射”按钮。WASD与鼠标瞄准保持独立。
- 检测仍显示真实选敌距离；弹体使用真实伤害几何。已在实际GPU中打开/关闭威胁显示检查连射过程中与清理后的图形。
