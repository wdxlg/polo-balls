# 长弓击退、背景选择和取景设置（2026-09-24）

## 行为与实现范围

- 天堂陨落长弓普通箭矢命中仍造成伤害、音效、命中特效、落箭雨及裂隙，但不施加击退。旧箭矢 `configure` 的位置参数保留为无效兼容参数，避免已有调用/测试错位；角色不再导出可调的箭矢击退值。瞬移到达的圆圈仍按原逻辑每跳对敌人施加小幅向外击退，未改伤害/攻击节奏。
- 背景选择统一读取 `地图背景主题.gd` 的六项：蓝色、草方块、沙地、石砖、下界岩、末地石。参数页下拉列表可选择全部六项，`Game_Settings.Map_Background` 仍是本机设置。地图内部/外墙改用所选纹理；外侧视差材质及门洞填充跟随主题；蓝色仍无贴图外墙，物理边界不变。新增主题中英文标签在 `translations.csv` 与 `global/translation_catalog.gd` 对齐。
- 参数页的「画面取景」选项和说明紧接「背景选择」，而非留在列表底部；录制页仍只含录制相关设置。
