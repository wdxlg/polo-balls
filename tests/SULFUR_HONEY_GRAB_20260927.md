# 硫方怪：1秒可挣脱抓取与铁/冰撞墙联动

日期：2026-09-27。本报告取代上一轮蜂蜜×0.25规则；铁、冰、紫晶的已确认平衡继续保留。

## 已实现的用户要求

- **纯蜂蜜零伤害**：没有本体接触伤害，也没有独立撞墙伤害；删除原蜂蜜伤害倍率，而不是保留为额外叠加。
- 每个敌人每次抓取最多 **1秒战斗时间**；各自独立计时，暂停不消耗时间，移动到旧槽不会重置计时。
- 固定 **170世界速度**的牵引贡献，不逐帧累加，不改写敌人的 `Repel`，不锁位置、输入或正常移动。敌人可用足够快的反向移动提前逃出接触范围。
- 超时后即使仍贴着，也不会下一帧重新抓住；须离开接触范围再进入。
- 超时、挣脱、失去蜂蜜、死亡/删除时清理自身牵引、免碰撞租约、墙回调和有效目标路径。不影响另一来源的租约或其他击退。
- **用户明确选择的联动**：施术者保留蜂蜜+铁或蜂蜜+冰时，当前被抓的敌人真实撞墙，由该敌人承受对应铁/冰速度伤害。不是施术者自伤，也不要求被抓者自己是铁/冰。
- 单独蜂蜜，或蜂蜜+岩浆/紫晶，不凭空获得上述墙撞伤害。岩浆、紫晶本身原有独立招式不在此禁用。

## 墙撞伤害

继续订阅公共 `wall_contact_impact(normal_speed,point)`，速度来自被抓者的真实相对墙内向速度；不使用施术者面朝方向、配置 `Speed`，也不把擦墙切向速度算成冲击。

| 有效组合 | 原始伤害公式 | 攻击48、无减伤，速度85 / 170 / 340 |
| --- | --- | --- |
| 纯蜂蜜 / 蜂蜜+非铁冰 | 无 | **0 / 0 / 0** |
| 蜂蜜+铁 | `floor(attack_damage(1.2075 × normal_speed / 170))` | **28 / 57 / 115** |
| 蜂蜜+冰 | `attack_damage(0.625 × normal_speed / 170)` | **15 / 30 / 60** |

- 铁/冰墙撞与原招式共用公式和施术者当前攻击，随后走公共普通伤害、防御和舍入流程。例：攻击48、速度170、目标减伤50%时，铁29、冰15；攻击96时同速铁115、冰60。
- 原铁本体仍仅真实向下砸中底部且同一接触一次；没有恢复静止碾压。新增的是被抓者撞墙载体，不是放宽普通铁的方向限制。
- 原冰本体仍为全方向实际碰撞速度伤害；原转向、反弹和冰面惯性保留。
- 公共墙接触去重防止持续顶墙重复扣血；暂停、非权威、友军、眩晕/禁止攻击、超时、挣脱和失去蜂蜜均不结算抓取墙伤。
- **同物理步边界已覆盖**：敌人可能在自己的 Move 中越过接触边界并立即撞墙，早于施术者下一次扫描。墙回调重新检查距离，先释放过期关系，不把这次已挣脱撞墙误算为抓取伤害。
- 同帧墙威胁的数值使用实际铁/冰公式；纯蜂蜜无虚构伤害威胁。

## 共享实现及联机

1. 现有 `knockback_effect.gd` 的距离型独占击退会重定向现有控制器，不适合每帧蜂蜜牵引。本次在**同一公共脚本**增添非独占 `set_pull/release_pull/pull_velocity`，没有另写一套击退、墙反弹或物理碰撞算法。
2. 公共 `ball.move/stand` 仅各增加一次贡献合成。每来源覆盖自己的贡献、弱引用隔离、失效/超期剔除，不写 `Repel`，也不创建新的控制锁。完全自行移动、不走公共 move/stand 的自定义载体仍须接入这个公共贡献接口；没有把所有私有移动分支视为已验证。
3. 复用现有成对免碰撞租约和大规模软分离查询；受击、地形、第三方碰撞、其他来源排除均保持。
4. 复用场景原有的 `honey_target_paths` 同步，不新增客机伤害或客机牵引。服务器计时和释放，客机同步有效名单；尚未到达的复制目标路径保留以便晚生成后解析。
5. 两槽FIFO、双展示框、内核最新块、TNT消耗/伴随特性、原版素材/音效、紫晶0.35/0.23625及冰面420/480参数未改。
