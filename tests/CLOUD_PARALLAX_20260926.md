# 云的镜头视差大于背景（2026-09-26）

## 用户要求与本次调整

用户要求：“云的视差效果应该比背景要大。也就是说视角移动的时候云移动的更多。”

本次采用 **1.25 倍相机投影位移**作为云层的统一视差：上空云与背景云都使用同一倍率。镜头向右/下移动时，云仍向画面的左/上移动，只是幅度更大，不反向跟随镜头。

- 原来蓝色上空云为 0.6，非蓝色背景云仅 0.25；后者比蓝色/草地的 0.32 和沙地的 0.30 背景移动还少。
- 将控制器的两个视差常量统一为 1.25；Shader 的默认值同步，并允许编辑器设置大于 1 的倍率。
- **没有降低背景速度来制造差异。** 六种平面背景仍是原来的 0.18–0.32；山巅仍用原有真实 Camera3D 透视投影。
- 自然飘动仍为原来的 **1.6 世界像素/秒**，不随此倍率加速。
- 不改原版 PNG、32×32 平铺云格、向下 32/3 厚边、白顶/0.70 下沿、不透明度或昼夜染色。
- 保留本机开关、暂停、重置、多岛补集、独立视口，以及山巅“山体 → 云 → 竞技场”的遮挡关系。

实际游戏代码仅改 `scripts/effects/我的世界/minecraft_clouds.gd` 的视差常量和 `shaders/minecraft_clouds.gdshader` 的默认值/范围。不改背景注册表、世界/相机控制器、山体或战斗逻辑。

### 不只检查参数，而是比较实际像素

新增夹具使用运行时云/背景 ShaderMaterial，在 0.5、1、2 倍缩放下分别做横向、纵向平移：六种平面背景 × 三种缩放 × 两个方向，共 36 组。

以相机投影位移 100 像素计：

| 内容 | 实测/验证位移 |
| --- | --- |
| 云 | **125 px** |
| 蓝色、草地背景 | 32 px |
| 沙地背景 | 30 px |
| 石砖背景 | 22 px |
| 下界背景 | 20 px |
| 末地背景 | 18 px |

每组云和背景都与各自对应位移后的图像逐像素匹配，零不符；强制用背景的较小位移去匹配云会失败，排除云没有真正移动或只是跟背景一起动的空检查。两种后端结果一致。

山巅另外读取**当前真实背景 Camera3D** 对最近山峰高度层的投影。三种缩放下，100 px 相机投影位移对应最近山体约 **95.24 / 90.91 / 83.33 px**，均小于云的 125 px；两个方向都保持正确。该项是实际相机投影数值，不把山体截图的局部纹理相关性冒充完整 3D 像素匹配。
