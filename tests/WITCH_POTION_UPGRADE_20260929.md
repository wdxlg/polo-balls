# 女巫药水逐次升级与瓶身30基础伤害（2026-09-29）

## 用户确认的规则

用户选择“每次生效都加一级”，不是“每瓶只加一级”：

- 女巫实际喝药完成、瓶子直接命中、地面药水区域每秒生效，都使目标已有的**对应持续效果有效等级 +1**。首次一级，最高沿公共上限255级。效果消失/清除后下一次从一级开始，不另存永久计数。
- 中毒、恢复、迅捷、力量、缓慢、隐身、凋零走同一公共状态实例。等级参与真实 Buff、持续伤害/治疗强度，不仅更新名称。
- 凋零瓶附带的虚弱也升级；凋零和虚弱分别读取自己的当前等级，不把两个等级强制设成相同。主药效被拒绝时，不绕过拒绝去添加虚弱。
- 瞬间治疗/瞬间伤害没有存续等级，本次保持一级瞬时效果，不虚构永久叠层。中毒/恢复仍为原无限持续时间，其他药水保留原默认寿命；不同来源的独立寿命、移除和等级回退仍由公共状态服务处理。
- 瓶子基础直击由50改为**30**，通过女巫基础20攻击 × 1.5计算，仍受当前攻击属性与目标防御影响。瓶身撞击与药效独立：对普通目标的瞬伤瓶是一级药效50 + 基础撞击30，不把二者合并成30。
- 来源仍有效时读取当前攻击；来源已销毁时保留发射时伤害快照。原生命600、药水概率、炼制/饮用动画、范围半径、区域1秒间隔、5.2秒寿命与音效保持。
