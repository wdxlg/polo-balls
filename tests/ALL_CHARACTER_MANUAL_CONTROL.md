# 全角色 C 键手控与按键适配：盘点和验证边界（2026-09-25）

> **状态：C 键路由和本轮逐角色适配已落地，尚未进行 161 人逐招的人工实战验收。** 以下仅声明源码核对、场景盘点与 Godot headless 夹具实际覆盖的内容；其他对话原有的未提交角色文件仍不得顺带纳入本次手控提交。

## 用户确认的规则

- 战场鼠标指向目标按 C 进入/退出直接控制；WASD 移动、鼠标指向瞄准。
- 各实体真实已有的主动动作按顺序分配：左键、右键、中键；第 4～13 招分别对应数字键 `1`～`9`、`0`（主键盘及数字小键盘）。不足三招的键空置，不重复绑定，也不捏造新技能。
- 控制中不由 AI 自动主动攻击/放技能；保留被动、受击、碰撞、死亡、技能冷却、蓄力与松键语义。多人仅服务端权威处理动作，客户端只传意图。
- 范围：全部选角人物和可以独立行动的召唤物/子实体；纯弹道投射物、静态障碍不伪装成可控角色。
