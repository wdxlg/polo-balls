# 全角色 C 键手控与按键适配：盘点和验证边界（2026-09-25）

> **状态：公共路由已落地，逐角色适配未完成。** 本文是当前工作树的静态盘点与已实际运行的测试记录，不代表每个角色都已经可以手动放出所有招式。另有并行对话尚未提交的角色脚本；按用户选择，在这些脚本归档/提交前暂停冲突范围，不能擅自纳入本次提交。

## 用户确认的规则

- 战场鼠标指向目标按 C 进入/退出直接控制；WASD 移动、鼠标指向瞄准。
- 各实体真实已有的主动动作按顺序分配：左键、右键、中键；第 4～13 招分别对应数字键 `1`～`9`、`0`（主键盘及数字小键盘）。不足三招的键空置，不重复绑定，也不捏造新技能。
- 控制中不由 AI 自动主动攻击/放技能；保留被动、受击、碰撞、死亡、技能冷却、蓄力与松键语义。多人仅服务端权威处理动作，客户端只传意图。
- 范围：全部选角人物和可以独立行动的召唤物/子实体；纯弹道投射物、静态障碍不伪装成可控角色。

## 当前已落地与已验证

- `global/game.gd`：鼠标三键和数字 `1`～`9`、`0` 的 13 槽输入；主机与远端按下/松开/持有状态、合法索引、切换/掉线取消、输入焦点过滤。未新增按键与屏幕 UI 的耦合。
- `classes/ball.gd`：通用动作序列只使用实际声明的攻击/技能或角色专用手动入口；空键无动作，中键不再默认重复右键/左键；独立行动的 Creature 须显式 opt-in，投射物不可通过该标记被选中。**opt-in 接口已实现，具体子实体仍需逐个接入。**
- `tests/test_all_character_manual_control.gd`：输入映射、13 个不同动作、按键松开、越界拒绝、数字键单次触发、取消、角色/子实体选择能力与两个真实 Attack/Skill 接口，共 **31 项，0 失败**（Godot 4.7.2 headless）。`tests/test_boat_onboard_control.gd` 原有回归 **41 项，0 失败**。这两项不是全角色实战验收，也不是双客户端联机测试。
