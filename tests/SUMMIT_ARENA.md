## 使用

`tools/preview_summit_map.gd` 可在独立 Godot 进程中打开真实战斗场景及原有操作界面，并仅在该进程预选山巅，不主动覆盖保存的设置：


## 实现与视觉

- 当前 `assets/maps/summit/shandian_natural.glb` 来自原生成器的自然峰顶／枝雪可选配置，保留原版贴图和 glTF 染色；旧 `shandian.glb` 及 `.gdignore` 隔离的 `art_sources/summit/山巅.blend` 未覆盖，新源场景独立保存在 `art_sources/summit_natural/`。
- `scripts/effects/summit_arena_3d.gd` 将两个同源山体实例放到浮空竞技场下方，并与新增的连续群山融合，让俯视战斗中也能看到多座雪峰。两个实例均使用统一比例；没有把山体压扁成贴图。每份山体 17 个网格、199,280 三角形。
- 地图本体是按实际岛屿矩形生成的 3D 冷灰石砖地面、裂纹/苔藓旧砖、旧石砖镶边、两层连续观战席及四角立柱。新增建筑按五种材质批处理；50×50 地图仍至多五个建筑网格。
- 竞技场与所有山体之间保留真实空气间距，不再由近处岩地承托；山峰均低于竞技场底座。动态竞技场地面仍对齐 Y≈0，不改变 2D 战场投影。群山是不可行走的远景，多岛内部空隙仍保留。
- 山体、竞技场和原 0.4 格低墙共用同一个实时 SubViewport、Camera3D 与 DirectionalLight3D；使用原相机最终画布同步和精度合成，绝对 Z=-4，位于药水/附魔框 -3 与战斗对象下方。场外遮罩继续从真实背景快照恢复，而不是盖住新景观。
- 看台只沿仍存在的外侧墙段布置，中心礼仪通道至少留 3.2 格；不填服务生门洞和传送口。建筑仅装饰，不添加 2D/3D 物理体或导航。
- 新主题直接在 3D 地面接影，关闭重复的地影通道；切回旧五种方块恢复旧通道，切蓝色停止 3D，切庭院不保留山体。昼夜沿用现有世界着色与太阳方向，不每帧重建网格。
- `previews/summit_natural_gameplay.png` 是实际主画面 GPU 截图，包含原有界面；HDR 2D 读回按正确方式转 sRGB。`previews/summit_natural_oblique.png` 是同一 3D 世界的诊断斜视图，**不是实际战斗相机**。常规战斗仍为原来的俯视 2D 角色玩法。

## 当前方案：原山最高、同源群山、精简竞技场

按用户最新反馈，已弃用上一轮粗大的程序锥形配山，不再用另一套低细节轮廓拼在原山旁边。

- **统一山脉细节**：周围山脉直接实例化同源修正版 `shandian_natural.glb`，沿用其不对称山脊、岩层、沟壑、冰川、雪线和云杉，不只是换一张贴图。通过 90°旋转、0.56～0.76 倍等比缩小和位置错落组成连绵群山；网格/材质资源共享，仍采用各网格正常视锥裁剪。保留原山模型文件和 Blender 工程，不覆盖源资产。
- **原山最高**：原始主峰移到竞技场后方可见处；周山底部处于同一谷地高度，坡脚交叠连接，而所有配山峰顶低于主峰。Map10x10 中原山最高点 Y=−96，配山网格 AABB 上界约 −203.8317，原山高出约 6.7 格。配山隐藏三份山顶标志网格，只让原山保留标志；检查实际匹配数量，不能只凭空集合通过。
- **精简场地**：取消 5.1 格宽的大面积外围石板，改为 0.55 格窄沿和 0.3 格薄底座；仍然浮空，不接触下方山体。四周只留两层连续长条观战席，先合并相邻墙段，不再每个墙格各堆一组小方块。标准地图共八段看台，中间留通道。
- **四角立柱**：恰好四根完整细柱，柱身高 3 格，配简洁柱脚/柱帽，不再用参差低矮石堆。柱子和座席均在可玩地面外；原 0.4 格无缝边墙、门洞/服务生入口及碰撞不变。
- 群山布置扩展到 13×13 邻域，扣除已有主山/后山位置后为 167 个周山实例；这不是单张画面同时可见的数量。实机正常视野四周/底部已补齐山形；远处谷底平面仍负责兜底，不声称任意极端取景下都有无限细节。
