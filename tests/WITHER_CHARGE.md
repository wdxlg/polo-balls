# 凋零冲刺至地图墙：机制与回归

入口：`scripts/characters/我的世界/wither/wither.gd`，真实场景回归：`tests/test_wither_charge.gd`。

## 行为

- 原 130 世界单位定距、`move_and_slide()` 受阻的冲撞改为固定方向、500 世界单位/秒的扫掠式冲刺。出发时计算**当前地图所在区域**沿冲刺方向的第一道边界，并扣除凋零碰撞体的半宽/半高；因此水平、垂直、斜向均停在地图墙内侧，不冲进外部或别的岛屿。移动不调用角色物理碰撞解算，障碍物、建筑墙和人物都不令凋零停下。
- 每帧从旧位置到新位置按凋零实体范围扫掠；路径内普通静态碰撞体、可挖矿的碰撞瓦片和数据驱动的地面障碍走现有 `GhastObstacleDamage` 可回滚破坏入口，一次冲刺即达到第 3 阶段碎裂；地图安全框/边界及该入口显式标记不可破坏的地形不会被拆。基于路径矩形二次筛选，路径外的障碍不受影响。障碍结果由权威端可靠同步给远端。`BuilderWall` 属于 `ball` 而非静态体，使用真实生命/减伤流程单独击毁。
- 敌人仍仅受一次原有 32 点伤害并被击退；破坏墙体后不会再被旧的遮挡判定挡住。设置 → 威胁显示的冲刺段从蓄力起预测到墙，冲刺时显示实际剩余段，结束立即隐藏；伤害带半径仍为原有 42。
- 世界 `reset()`/重打使 `_mc_placement_generation` 更新后，凋零独立的 `charge_reset.gd` 监听器调用共享管理器 `reset_all()`，恢复本轮已拆的持久障碍；凋零死亡时不会在对局中途把障碍还原。轮放训练的小局清场若没有新一轮的 generation 增量，则不会单独重置地形。

## 验证范围

运行项目离线引擎的 `--headless --script res://tests/test_wither_charge.gd`：真实 World/Map50x50 **15 项检查、0 失败**，覆盖自动蓄力、冲刺长度超过 130、两个实体障碍/碰撞瓦片/建筑墙清除、路径外及安全墙保留、敌人一次伤害、斜向第一面墙、威胁终点与真实地图重置后的恢复。已有 `tests/test_wither.gd` **9/9**、`tests/test_wither_live.gd` **55/0** 同轮通过。此处为无头真实物理场景，不等同于完整 GPU 画面或双客户端联网验收；网路破坏沿用现有管理器可靠 RPC，但尚未进行双端实测。

`scripts/effects/我的世界/ghast_obstacle_damage.gd` 目前是另一项工作的未跟踪文件，本次不修改、不提交。冲刺复用其现有 API；要获得可跨清理工作区独立重现的完整 Git 版本，需要其所属工作先纳入版本。`MCP_CONTEXT.md` 同样正在由另一项工作修改，本轮为避免覆盖不改动该索引。
