# 铜剑 / Copper Sword

新增入口：`我的世界 → 铜剑`，场景 `scenes/characters/我的世界/铜剑.tscn`。

## 行为

- 原版铜剑物品贴图，平时只跟随移动方向朝左/右；攻击按敌人的真实方位做 360° 瞄准（包括正上/下和斜向），不是只切换左右贴图。每段连刀保持贴图镜像一致，换目标时在慢起阶段平滑转向，不会改写移动方向、速度或 WASD 输入。
- 攻击（包括首次起剑与连续挥剑）时，主动移动速度为平时的 85%；停攻/打断进入回收时恢复。不改写 `Speed` 或覆盖其他增减速效果，击退与拥挤分离仍走公共移动逻辑。
- 身体碰撞框、被动 Hitbox 与 Hurtbox 都改为原版 16×16 剑图**下方剑柄/柄头**处的窄胶囊，三者每次视觉姿态更新都随贴图平移、镜像和旋转；不再用居中的 72×88 人形矩形。根节点局部胶囊半径 11.25、高 63.75（根节点缩放 0.2），中心对应贴图右朝向像素 (-4.5,4.5)。被动身体碰撞伤害仍关闭；主动挥剑的整把剑凸包与独立扫掠伤害范围保持原样，不能误缩成剑柄。
- 实际挥剑角速度超过 16 rad/s 时留下短暂原版剑身残影，随连击/外部攻速提高自然出现；慢刀、单纯跑动、起剑和回收不生成残影。残影保留采样时的世界坐标、旋转、镜像、氧化颜色，0.14s 内消退，最多 10 个，只渲染、不参与伤害。暂停冻结、死亡/隐藏清除。
- 不再显示铜剑的锈蚀、附电时间、连击/倍速文字。保留正常血条和其他公共状态提示；生锈及附电只通过剑身颜色、闪光和电弧表现。
- 每刀以 ease-in 曲线先慢后快（`phase^2.4`），围绕原版剑柄旋转。上斩/下斩连续往返：上一刀终点就是下一刀起点，中途没有归位段、重复起剑或攻击间隔；只有首次攻击起剑。没有后续目标/松开长按后，完成当前一刀再以 0.12s 的快速回收恢复左右待机；眩晕/禁攻立即停刀并回收。回收不造成伤害。
- 每次实际造成伤害的完整挥剑增加一层连击；攻速直接缩短实际挥剑时长，而不是只缩短等待。使用原图透明像素生成的武器凸包与真实 Hurtbox 进行随角度/位移的子步扫掠，一刀扫中多人只加一层、同一敌人同一刀只受一次伤害；不会通过墙体打人。挥空、动作受控打断、禁攻或超过续击窗口重置加速。
- 持续氧化为斑驳铜、锈蚀铜、氧化铜颜色。全锈后保留绿色并播放引雷预警，雷击实际落下才清锈、赋予短暂附电。不是计时到零时提前清锈。
- 自身引雷在预警期跟随剑的位置，伤害/眩晕附近敌人，不伤自身或同队。带电近战命中会在接触地点引雷；后者固定地点、短预警，不跟着攻击者移动。
- 电击不会递归触发更多电击，也不增加近战连击。附电结束时闪光和剑身电弧一并消失。附电期间仍继续生锈。
- 主动攻击服从 `Can_Attack`、眩晕、禁攻和权威端限制；生锈是被动技能，服从 `Can_Skill`/禁攻，但不会被普通眩晕暂停。布阵、战斗暂停、死亡时不推进游戏计时或额外结算。
- 单击完成一刀；长按会连续反向挥剑。松开后完成当前一刀再快速收回，不额外续刀；取消控制/禁攻则立即停止伤害并收回。技能被动触发，右键不能绕过生锈阶段提前清除。

## 复用与素材来源

- `MC_COPPER_SWORD_ASSETS.json` 记录 Mojang 官方固定提交、5 个原始 PNG 的 URL / SHA-256；`fetch_copper_sword.py` 可校验或重新下载，不覆盖内容不同的现存文件。
- 生锈使用**原版铜块各氧化阶段贴图**在 shader 中对原铜剑金属部分着色，不冒称原版有“氧化铜剑”物品；不生成手绘替代贴图。
- 雷击直接实例化既有 `trident_lightning.gd`。附电只增加铜剑位姿适配，继承 `trident_charge_visual.gd` 的同一原版附魔纹理、shader、剑身电弧生成及绘制。未改动溺尸或三叉戟的既有行为。
- 挥剑/伤害/受伤/破碎复用原版近战、玩家受伤、物品破碎音效；引雷、落雷和附魔复用三叉戟原有原版音效反馈通道。关闭铜剑自带的通用球体音效。
- Minecraft 素材仍归 Mojang 所有，受相关 EULA/许可约束；公开下载不构成商用或独立发行再分发授权。

`test_copper_sword.gd` 使用真实 World 和 Hurtbox，覆盖角色索引、原图 hash、左右朝向、上下交替、实际命中/去重、攻速递增与上限、挥空/超时重置、墙体阻挡、暂停/眩晕/禁用门禁、全锈预警与落雷清锈、伤害/眩晕/同队保护、附电特效来源、命中引雷/防递归、附电到期、非权威端、死亡清理。

`test_copper_sword_live.gd` 让真正的状态机自然运行，验证自动挥剑、生锈清除、带电命中雷、暂停及技能禁用；不由测试手动调用攻击/技能 tick。

`test_copper_sword_visual.gd` 在真实 GPU 渲染器下做像素级验证，输出 `tests/copper_sword_visual_contact.png`。图中顺序：干净铜剑、斑驳铜、锈蚀铜、完全氧化；附电、上抬准备、下抬准备、朝左。该图是可视化检查，不代替战斗测试。

Windows GUI 版 Godot 可能不会向 PowerShell 同步传递退出码；自动化请用 console 版本，或 `Start-Process -Wait -PassThru` 获取进程的 `ExitCode`，并同时核对日志中的检查计数/失败数。
