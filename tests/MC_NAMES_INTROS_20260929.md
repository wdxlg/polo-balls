# 我的世界英文名称与盔甲架介绍（2026-09-29）

## 范围与结果

按用户确认，只修订「我的世界」分区的英文名和全部角色介绍；其他分区不改文案。长期命名/介绍规则适用于全项目新增或更新角色。

- 实际盘点 `scenes/characters/我的世界/*.tscn`：46 个角色。
- 补全缺失英文名：凋灵骷髅 → **Wither Skeleton**；石矛 → **Stone Spear**；钻石长矛 → **Diamond Spear**。
- 名称核对 Minecraft Java 1.21.11 `en_us.json` 的 `entity.minecraft.wither_skeleton`、`item.minecraft.stone_spear`、`item.minecraft.diamond_spear`。本轮读取的原版语言数据镜像：<https://raw.githubusercontent.com/misode/mcmeta/1.21.11-assets/assets/minecraft/lang/en_us.json>。镜像提供的是原版语言资源，不把项目原创组合角色的名字冒称官方译名。
- 46 份中英文战斗介绍统一使用 `MC_ARMOR_INTRO_*` 稳定键，正文在 `translations.csv` 中维护。保留现有世界介绍入口和自定义 getter，不新建另一套 HUD。
- `scripts/world.gd` 的回退介绍通过 `Game.t` 解析；13 个角色的自定义 getter 改为引用同一翻译键。英文主界面、整段录制翻译和中文回译保持一致。
- 根据实际脚本补齐：流浪商人及羊驼补回、硫方怪六种方块、骷髅插箭处决、唤魔者图腾、钻石剑升级、复制/分裂存续、成长与控制限制等。删除按键、外观、音效、历史改版、实现过程和重复套话。
- 纠正旧文案而不修改玩法：羊脚本将通用 `Damage_reduction` 设为零，不再写「羊毛减伤」；普通弓使用 `configure_plain`，没有骷髅插箭处决；重锤的高度/范围上限不是伤害增长或续跳次数上限；流浪商人当前代码有阵亡羊驼冷却补回，而旧规则摘要仍写不复活。以当前实际代码为准，本轮不覆盖其他任务的历史规则条目。
- 中文正文最长 164 字；复杂机制用概括描述，不堆全部数值。体型仅在影响碰撞或复制属性时保留。
- `MCP_CONTEXT.md` 新增长期规则：新角色中英文名、已有官方译名必须采用、查不到时不得冒称官方、所有角色的盔甲架介绍要简洁完整且限于实际战斗机制。
