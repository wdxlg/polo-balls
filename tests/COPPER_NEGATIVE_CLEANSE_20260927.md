# 雪傀儡425生命 / 铜剑自然落雷公共负面净化

日期：2026-09-27。用户确认：**只清除负面效果，保留正面药水与增益**。

## 已实现

- 雪傀儡基础最大生命 **360 → 425**。攻击9、速度80、默认2秒攻击冷却及原雪球/积雪规则不变。半血按当前最大生命计算，整数生命213尚未碎头、212触发一次碎头并保证下一轮连射；对应现行测试和有声预览改用比例阈值，不改历史补丁。
- 铜剑只在**锈满自然落雷实际落下**的成功回调净化自身。预警期间不会提前清除；暂停不推进落雷；攻击命中召来的雷不净化。原除锈、附电、范围伤害/眩晕与连击入口保留。
- 清除负面药水的全部来源（包括无限来源），以及灼烧、寒冷/冻结、流血、凋零、Karma、敌方击退/眩晕/真实击飞、黏附、箭伤与待执行斩杀等。蜂蜜的外部抓取记录、成对免碰撞和墙伤回调同步释放；仍须重新接触才可再抓。
- 力量、抗性、迅捷、隐身等正面状态保留原节点/等级/来源/剩余时间；中性自主运动、其他角色与独立控制所有权不被清空。只清自己的负面状态，不删除地形或持续伤害源；不治疗、不提供额外免疫，后续合法命中可以重新施加。
- 属性在当帧通过公共 Buff 数值应用函数刷新；不推进药水时间/全局中毒钟，也不触发寄生到期爆炸。药水受伤/死亡监听立即断开，旧斩杀回调拒绝执行，不能在延迟删除前补触发。
