# 对战录制（2026-09-23，录制速度与中文文件名修复）

## 本次：修复双路编码拖慢游戏及导出慢放

### 实际复现与修复

旧实现把两个 1080×1920 RGBA 帧流在游戏主线程同步写入 ffmpeg，再按真实经过时间补帧。双路 `libx264 veryfast` 编码的阻塞与 CPU 争用会令 Godot 的物理步进追不上墙钟；补帧又加重下一轮写入。实际复现：录像时钟 **4.753553 秒**，独立物理节点只推进 **3.0 秒**，所以“标称 60fps、音视频等长”不能证明播放速度正确。

- 新增 `battle_record_writer.gd`：独立线程写编码管道，主线程只提交不可变像素数据；同一旧图补多帧只入队一次，在工作线程重复写，不让 ffmpeg 反压冻结游戏。
- 每种语言最多 **128 MiB** 像素数据 / **120 帧**排队，超限明确停止，不无限占用内存或阻塞游戏。停止时异步等队列写完；管道超时会终止本会话编码器；场景退出会回收线程。
- 用真实输出尺寸探测 NVENC，支持时优先 `h264_nvenc` / P4 / const-QP 16 / 零延迟配置；不可用时回退 `libx264 ultrafast` / 2 线程 / CRF 14。两种后端都实测速度，不仅凭编码器列表推断可用。
- 中英文仍共享画面时钟、暂停门控与音频，保留旧图填旧时隙；异常时以共同帧数截取成对已完成片段。
- 独立物理时钟监测持续减速：预热后若两秒窗口的实际物理进度不足应有进度的 90%，明确报错停止，不生成宣称正常速度的正式成片；保留临时材料。不擅自提高用户的游戏速度，也不靠随意改 MP4 帧率掩盖问题。
- LIVE 不再被同步编码拖成慢放；SIM 采集仍有意以 0.25 倍运行，输出按正常游戏时间恢复。该修复不保证任意人物数/特效负载下硬件都能实时运行，超载会提示而不是静默输出慢放。

## 双语输出与对阵命名

每次左键 LIVE 或右键 SIM 都生成两份独立有声 MP4，**不是复制同一画面换文件名，也不是重打两局**。两个视口共享同一个 World2D、同一个捕获时钟和暂停门控，成对填充旧帧；同一条 GameplayRecord 音轨分别合成。角色位置、攻击、结果和时间线一致，只替换有现成翻译的可见文字。

### 文件名规则

- 普通对战：`中文_钻石剑 vs 木剑 vs 牛_时间戳.mp4`；`英文_钻石剑 vs 木剑 vs 牛_时间戳.mp4`。
- 同队多个固定人物用 ` + `，不同阵营按首次出现顺序用 ` vs `。
- 整队随机：`中文_3人随机队伍 vs 3人随机队伍_时间戳.mp4`；`英文_3人随机队伍 vs 3人随机队伍_时间戳.mp4`。
- 单独随机人物的文件名显示“随机人物”；固定与随机混合的队伍显示固定姓名 + 随机人数。
- 轮放对决、逐个挑战在对阵前加中文模式名。
- 计时：两份均为 `计时60秒_…`，使用实际设置时长。
- Boss：两份均为 `Boss模式 x3_…`；车轮战则均为 `Boss车轮战 x3_…`，使用实际倍率。
- 盔甲架测试与手动训练另加相应模式名。
- 阵容、模式和随机来源在开始录制时快照，人物死亡不会改变文件名；SIM 取用于重打的布阵。不从随机抽中的名字猜“是否随机”。
- Windows 非法路径字符会替换；过长标题截断并加校验后缀，完整标题保存在 MP4 title 元数据，视频轨分别标记 `zho` / `eng`。目录过长会明确提示换短目录，时间戳避免常规同名覆盖。

## 前版：与游戏颜色一致，剔除 Esc 暂停与恢复等待

- 旧离屏视口强制 SDR，虽然不透明色卡能通过，但与主窗口 HDR 2D 的半透明混合结果不同，且遗漏 Game 常驻暗角。现在共享主窗口的 HDR/抗锯齿/像素对齐设置，只复制常驻暗角；不复制 `Stop_Ui`、工具栏或模拟遮罩。
- HDR 画面先在 GPU 以浮点精度转换到 sRGB，再读回 RGBA8；不先量化 HDR 再补 gamma，避免暗部丢失。录制暗角使用正常对战 SCALE，不跟随暂停/恢复的变暗动画。

## 实现要点

- `scripts/ui/battle_recorder.gd`：渲染、帧时钟、编码、结束判定及清理。
- `scripts/ui/battle_record_audio.gd`：只在 GameplayRecord 总线上追加临时 AudioEffectCapture；声音流式写入 f32 stereo PCM，不将整场音频累积在内存。移除时按实例匹配，仅清理自己的 effect。
- `scripts/ui/battle_record_controls.gd`：按钮状态、提示与结果窗口。
- UI 音频走现有独立 UI 总线，不经过游戏录音入口；不采集麦克风或桌面声音。
- 既有 Audios 会令游戏声音跟随 Engine.time_scale；SIM 采集以同一倍率重采样，抵消模拟慢放，恢复正常音高。尊重游戏总线和 Master 的音量/静音设置，不改动用户混音设置。
- 对战画面采用与主窗口一致的 HDR/SDR 渲染，HDR 时用额外的 GPU sRGB 解析视口输出 RGBA8；透明混合、暗角与暗色不依赖猜测 gamma。
- 根据逻辑视口映射相机，不使用 Window 纹理的缩放后尺寸再次缩放相机。小窗口与原生输出构图一致。
- 掉帧补帧使用上一张画面，而不是把新命中/闪光提前填入过去的时间段。严重渲染阻塞或音频缓存溢出明确停止，不静默缩短视频导致漂移。
- 先输出视频临时文件与 PCM，再复制视频流、仅编码音频完成合成。成功后删除临时文件；合成失败保留恢复材料并报错。
- 没有可用 ffmpeg 时仍能降级为 PNG 序列与独立 PCM，**不能把该降级产物称为已经合成的有声 MP4**。
