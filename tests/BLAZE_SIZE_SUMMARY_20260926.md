# 烈焰人本体缩小与盔甲架说明（2026-09-26）

## 修改

- 本体可见尺寸缩小20%：`body_size_vs_creeper` 默认1.0→0.8，保留原逐帧动画和原生模型适配。测试在native动画attach完成后检查世界尺寸仍恰为旧值0.8，未缩整个根节点。
- 对应身体碰撞矩形78×155→62.4×124；受击矩形74×150→59.2×120。原无本体碰撞伤害的hitbox共用身体形状，仍不额外造成伤害。
- 两根外侧烈焰棒的图片、18×72物理形状、24×78攻击区、环绕半径及展开攻击距离不变；血量520、攻击28、弹速330、火场半径34等也不变。
- 使用已有角色接口 `get_armor_test_effect_summary()`，由World盔甲架说明优先读取，不修改共享World的旧一行回退表。中英文各三段，连发数量/灼烧时间/火场时间读取当前导出参数。

当前中文默认说明：

> 连射3–5枚烈焰弹，命中造成火焰伤害并附带3.2秒灼烧，使敌人持续掉血。
>
> 烈焰弹打到地面或障碍物会在落点生成火焰，持续4.5秒；踩入火焰会受到周期伤害并被点燃。
>
> 两根环绕的烈焰棒是实体挡伤障碍，可挡住击中棒体的箭矢等可被阻挡的投射物，替本体挡伤；攻击时向外展开并加速旋转，碰到敌人也会造成伤害。

这不是新增灼烧、火场或无敌盾。已核对原烈焰弹：命中敌人走公共火焰伤害并施加共享灼烧，命中地形则生成原火场。烈焰棒是实际AnimatableBody2D障碍，骷髅箭已有明确截停入口；不承诺挡住所有范围攻击/穿透技能，不能把“棒子挡伤”解释为本体全方向无敌。棒的接触攻击沿原普通位置伤害，不误改成火焰。
