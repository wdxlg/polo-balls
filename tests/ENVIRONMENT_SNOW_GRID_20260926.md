# 环境雪：全屏飘雪与实际一方块积雪

## 本次要求与范围

用户纠正：环境下雪应覆盖全屏，不局限地图；环境积雪应是一个实际方块的大小，墙上也一样。

本次将**飘落天气的覆盖**和**积雪的方块几何**分别修正。并未把每个空中小雪花改成一个实心方块，也未改变角色技能、地图碰撞、镜头控制、云形状/视差、山巅聚焦、录制命名或素材。

### 实现

- 原天气绘制范围由地板包围盒扩展192世界单位而来，且Z=8仍在地图外遮罩Z=90之下。现在天气使用独立于地图的固定大世界覆盖范围（当前坐标±1,000,000），仍只有三次原版降雪贴图绘制；绝对Z=4095使其越过地图外遮罩和顶层云，保留昼夜着色，低于菜单CanvasLayer。没有每雪花节点，没有使用不随暂停停止的shader TIME。
- 环境候选读取 `world.map_visual_cell_size()`，相对于真实地板网格起点生成；通常16×16。墙顶也是一块墙方块的占地，原版2/16比例对应2单位厚，而不是原来的24单位占地/3单位厚。非均匀缩放地图按真实尺寸处理，不硬编码全部地图为16。
- 原雪傀儡/小雪人雪径的24/12尺寸、8/4战斗秒融化均未改变。两种格不能仅靠相同整数ID合并。
- 环境记录携带 `tile: Rect2` 的完整方块位置/尺寸；`rects` 表示真实接触/可见区域。旧的不带tile记录兼容原24单位格式。环境接触、快速穿过、矩形威胁、南瓜消耗、发育分区位移/合并及可靠增量/晚加入快照都使用真实几何；不是只缩小绘图。
- 共用原雪地管理器、碰撞查询、逐目标冷却、寒冷入口和音效。环境地面仍默认每次3点、积寒8、间隔0.5秒；普通/环境重叠不双跳。威胁列表按真实矩形去重，不让同号不同尺寸的格互相消失。
- 真实六面体墙雪、原版贴图/侧面UV、同一墙World3D/相机/光照/阴影保留。按实际支撑和门洞裁切；蓝色薄边框仍薄，不凭空改成完整方块墙。墙雪及空中天气仍纯视觉、无伤害。
- 保持初始空白、0.9秒天气渐入、2秒后开始积累、后续0.45秒尝试、1024永久格上限、独立随机流、权威生成及客户本地天气。

原版资产没有改像素、重绘或新增生成素材；来源仍为 `Images/effects/我的世界/雪环境/SOURCE.json`，不把原版来源理解为自由再分发授权。
