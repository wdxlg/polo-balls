# 循环时间与昼夜光照（2026-09-26）

## 当前行为

- 新 World 默认 **12:00**，右上角工具栏下方显示 `HH:MM`。时钟没有鼠标事件，不遮挡现有按钮；数字无需语言翻译。
- **1 秒游戏时间 = 1 分钟世界时间**，1440 秒游戏时间完成 24 小时，跨越 `23:59 → 00:00` 后持续循环。分数分钟逐物理帧推进，时钟文字仅在分钟变化时刷新。
- 暂停（`Game.now_stop_state` / SceneTree pause）与零倍速停止计时，恢复时不补算现实经过时间；普通倍速/慢动作沿用 Godot 已缩放的物理 delta，不重复乘倍速。镜头渲染与多路录制抓帧不会额外推进时间。
- 太阳指的是现有真实 3D 墙光源，不另造 MC 太阳素材：**12:00 右上 → 18:00 右下 → 00:00 左下 → 06:00 左上 → 12:00 右上**，连续顺时针旋转，一昼夜一圈。
- 昼夜曲线：**08:00–16:00** 保持原白天亮度；**16:00–20:00** 用 smoothstep 渐暗；**20:00–05:00** 保持冷色夜间亮度；**05:00–08:00** 平滑恢复白天。夜间仍能辨识战场，`NIGHT_TINT = Color(0.48,0.54,0.68,1)`；实际 HDR 线性读回比值通过 GPU 像素回归验证，不把 sRGB 参数直接当作线性亮度。
- 六种地图背景统一参与昼夜；蓝色仍没有 3D 墙。五种方块墙仍是 **0.4 格高、连续无缝**，太阳投影的几何总长仍约 0.6 格，昼夜只转光源并随夜晚淡出太阳影子，不恢复旧高墙/长影，也不改变物理碰撞。
- 换背景、切地图、开门/关门保持当前时间。清空战场与有效的普通重打/轮换重打入口回到 12:00；空阵容的无效重打不重置。右键离线录制不走重打入口，因此延续点击时的当前时间。

## 实现与边界

- `scripts/day_night_cycle.gd`：唯一时间状态、时间/方向/亮度公式、世界乘色层与主画面时钟。由 `World._physics_process(delta)` 驱动，而非系统墙钟或 `_process()`；公开 `set_minutes()` / `reset_to_noon()` / `time_text()`，`advancing` 可用于测试冻结。
- 某些真实背景/角色 shader 使用 `render_mode unshaded`，普通 `CanvasModulate` 不足以统一压暗。因此用默认世界画布最上层的 `Polygon2D` + `CanvasItemMaterial.BLEND_MODE_MUL`，覆盖普通及 unshaded 战场内容。白天直接隐藏乘色层，保留原本颜色和光照。
- 菜单、工具栏、时钟及独立屏幕画布标题不被该世界乘色层压暗；镜头移动不改变昼夜相位。乘色层是 World 的子节点，离场一起销毁，不修改全局主题或材质资源。
- `地图立体墙.gd::update_time_lighting()` 只更新两路真实光源和阴影 alpha，不调用 `configure_regions()`；连续时间更新时 ArrayMesh 实例 ID 与方块数量保持不变。主题/门洞重建后重新应用当前亮度。
- 所有录制/总览共享 World2D 的视口自然收到同一乘色层；时钟是主视口 CanvasLayer UI，**不额外加入纯对战双语视频**。已验证共享视口 GPU 明暗一致，但没有完成双语编码视频端到端测试。
- 不改变攻击、受击、MC 生物属性、原版素材或音效。没有新增天气、夜间刷怪、太阳/星空贴图、保存进度功能，也没有新增服务器时间同步协议；多客户端进入时刻不同可能存在时间偏差，不能把单机结果宣称为联机同步已验收。
