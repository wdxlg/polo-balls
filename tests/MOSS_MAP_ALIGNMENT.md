# 苔藓铺设与地图地砖对齐（普通模式）

## 现象及可复现数值

用户截图的 10×10 草地实际地面是世界坐标 `(0, 0)–(160, 160)`，地砖每格 **16×16**；原苔藓网格／可视贴图却按 **24×24**、以世界 `(0, 0)` 为中心铺设。中心落在 `(0, 0)` 的贴图上半块会进入墙面；第一列若从 `(24, 24)` 开始，左侧留下约 12 像素空带。160 也无法被 24 整除，因此单靠禁止越界无法铺齐两端。

| 地图 | 真实地面外接矩形（世界坐标） | 地砖尺寸 |
| --- | --- | --- |
| Map10x10 | `(0, 0)`，`160×160` | `16×16` |
| Map30x30 | `(1209, -9)`，`480×480` | `16×16` |
| Map50x50 | `(500, 942)`，`800×800` | `16×16` |
| Map_Portal | `(0, 2200)`，`448×256`；内部另有空隙和独立岛 | `16×16` |

## 本轮修复

- `moss.gd`：苔藓 CELL 改为地图真实的 16 像素，以所选地图真实地面矩形的左上角加半格为锚点；网格 ID 保留全局坐标性质，新增逆映射供真实铺设、预览和钻地特效共用。种植前要求**整个** 16×16 格位于实际占用地面区域的并集内；不再仅凭中心处的圆形碰撞查询放行。
- `moss_footsteps.gd`：脚步声查询使用苔藓拥有者的同一网格，不继续使用独立的 24 像素硬编码，避免隔壁空格误响或漏响。
- `test_mc_moss_feedback.gd`、`test_mc_moss_azalea.gd`：已跟踪的测试夹具使用真实格心／动态 CELL。新增 `test_mc_moss_map_alignment.gd` 覆盖三种普通地图首末格、岛屿空隙、边缘预览和脚步声格位。
